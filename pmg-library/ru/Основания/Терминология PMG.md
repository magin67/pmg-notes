Справочник фиксирует терминологию [[Спецификация ядра PMG|спецификации ядра]], [[Вводная серия PMG|вводной серии]] и опубликованных тематических серий. Для каждого понятия приводятся русское название, рекомендуемое английское соответствие и краткое определение. Условия применимости и основные тождества ядра содержатся в спецификации; определения расширений, доказательства и примеры приведены в связанных заметках.

## Область действия и статус терминов

Основная модель представляет собой конечный связный неориентированный граф без петель с положительными проводимостями существующих рёбер. Алгебраические определения не требуют выбора графа. Особенности несвязного случая оговорены в спецификации. Термины балансовой модели выделены в разделе [[Терминология PMG#Балансовые графы и направленная метрика|«Балансовые графы и направленная метрика»]]; симметричные формулы не переносятся на него автоматически.

В таблицах используются три обозначения статуса:

- **Стандартный:** термин применяется в обычном математическом смысле в указанной области.
- **С оговоркой:** термин известен, но в данном тексте требуется уточнение объекта, соглашения или нормировки.
- **PMG:** термин или специальное употребление, принятое в проекте.

Статус термина не характеризует доказанность утверждений. Английские соответствия собственных конструкций PMG являются редакционными рекомендациями, а не утверждением об их общепринятости.

Название проекта сохраняется в форме **Polyform Metric Geometry (PMG)**.

## Наборы и разбиения

Эти соглашения используются в [[Разбиения и комбинаторный потенциал второго рода|комбинаторной серии]]; краткая запись операций закреплена в [[Спецификация ядра PMG#Наборы в комбинаторных формулах|спецификации]].

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Числовой набор | numerical collection; multiset | С оговоркой | Конечное мультимножество $\mathbf x=[x_1,\ldots,x_m]$: порядок несущественен, повторения сохраняются. Набор обозначается жирной буквой, его элементы — обычными. |
| Размер набора; мощность | size; cardinality | Стандартный | $\#X$ — количество элементов конечного множества или вхождений в наборе. Для $\mathbf x=[x_1,\ldots,x_m]$ имеем $\#\mathbf x=m$. Термин «длина набора» не используется. |
| Вес числового набора | weight of a numerical collection | С оговоркой | $w(\mathbf x)=x_1+\cdots+x_m$. Отличается от размера набора и от аффинного веса элемента $V$. |
| Произведение набора | product of a collection | PMG | $\mathbf x!=[x_i]!=x_1\cdots x_m$; пустое произведение равно $1$. Аргумент является набором, тогда как $n!$ — обычный факториал числа. Запись $[x_i!]!$ означает произведение факториалов элементов, а не факториал произведения. |
| Кратность значения | multiplicity of a value | Стандартный | $\mu_j=\#\{i:x_i=j\}$ для каждого различного значения $j$ в наборе. Набор $\boldsymbol\mu=[\mu_j]_{j\in J}$ индексируется множеством $J$ различных значений; равные кратности сохраняются. |
| Разбиение числа | integer partition | Стандартный | Числовой набор положительных целых чисел заданного веса $w$. Его элементы называются частями. |
| Разбиение множества; блок; компонента разбиения | set partition; block; partition component | Стандартный | Набор непустых попарно непересекающихся подмножеств с объединением, равным исходному множеству. Блоки не пронумерованы; их количество обозначается $m$. |
| Числовой тип разбиения | numerical type of a partition; block-size type | С оговоркой | Набор размеров блоков $[\#B_1,\ldots,\#B_m]$. Его размер равен числу компонент, вес — размеру исходного множества. Отличается от типа формы разбиения по грейдам. |

В $[x_i!]$ сначала строится новый набор по тем же индексам, что у $[x_i]$, с сохранением всех вхождений; внешний знак в $[x_i!]!$ затем задаёт произведение. Обозначения числа, набора, симплекса и формы различаются по типу аргументов, а не только по наличию квадратных скобок.

## Точки, векторы и внешние объекты

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Базовая вершина | basis vertex | PMG | Элемент $a_i$ фиксированного линейно независимого базиса формального пространства $V$. |
| Точка | point | С оговоркой | Элемент $x=\sum_i x_i a_i$ с $\sum_i x_i=1$. Не всякая точка является базовой вершиной. |
| Аффинный вес | affine weight | PMG | Значение линейного функционала $\varepsilon(x)=\sum_i x_i$. Не вес ребра и не физическая масса. |
| Аффинный вектор | affine vector | С оговоркой | Элемент $u\in W=\ker\varepsilon$. В рамках ядра допустимо сокращение «вектор». |
| Вектор пары вершин | vertex-pair vector | С оговоркой | Разность $a_{ij}=a_j-a_i=(ij)$. Определена и при отсутствии ребра; обращение порядка меняет знак. |
| Пространство аффинных векторов | space of affine vectors | С оговоркой | Подпространство $W\subset V$ размерности $n-1$, состоящее из комбинаций с нулевой суммой коэффициентов. |
| Внешнее произведение | exterior product; wedge product | Стандартный | Произведение $XY$ во внешней алгебре, обычно обозначаемое $X\wedge Y$. Для однородных объектов при перестановке возникает знак, зависящий от грейдов. |
| Внешний объект | exterior-algebra element | С оговоркой | Элемент $\Lambda^kV$ или $\Lambda^kW$. Может быть линейной комбинацией внешних произведений. |
| Простой внешний объект | decomposable exterior element | Стандартный | Объект, представимый одним внешним произведением. «Простой» здесь означает разложимость в такое произведение. |
| Грейд | grade | С оговоркой | Внешняя степень $k$ объекта из $\Lambda^kV$. Для формы равен общему грейду её аргументов. |
| Симплекс | simplex | С оговоркой | Формальная запись $[a_1\ldots a_k]=a_1\cdots a_k$. Её грейд равен $k$; геометрическая размерность невырожденного симплекса равна $k-1$. |
| Ориентация | orientation | Стандартный | Выбор знака внешнего объекта, задаваемый порядком образующих. Перестановка двух образующих меняет знак. |

Обозначение $a_i$ в алгебраической конструкции не означает центрированный радиус-вектор евклидовой реализации. Формальные вершины линейно независимы; центрированные радиус-векторы имеют нулевую сумму.

## Граница и граничный оператор

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Граничный оператор | boundary operator | С оговоркой | Линейный оператор $\partial$ с соглашениями $\partial a_i=1$, $\partial1=0$ и обычной знакопеременной формулой удаления вершины. Это соглашение включает скалярный грейд. |
| Граница симплекса | simplex boundary | С оговоркой | Объект $(a_1\ldots a_k)=\partial[a_1\ldots a_k]$ грейда $k-1$, если он ненулевой. |
| Граница | boundary | С оговоркой | В данной алгебре любой объект из образа $\partial$. В грейде $k$ пространство границ совпадает с $\Lambda^kW$. |
| Пространство границ | space of boundaries | С оговоркой | $\Lambda^kW$ в фиксированном грейде; оно также совпадает с ядром $\partial$ в этом грейде. Равенство ядра и образа относится к данной конструкции. |
| Правило слияния | boundary merging rule | PMG | Произведение границ симплексов с единственной общей базовой вершиной даёт границу объединённого симплекса с соответствующим ориентационным знаком. |
| Правило обнуления | vanishing rule | PMG | Произведение границ симплексов с не менее чем двумя общими базовыми вершинами равно нулю. |

Правила слияния и обнуления применяются к границам симплексов на базовых вершинах. Для произвольных линейных комбинаций используется билинейность произведения.

> [!note] Два смысла слова «граница»
> Алгебраическая граница является образом оператора $\partial$. В задаче Дирихле «граничные вершины» означают выделенное множество вершин, на котором заданы значения. Это разные понятия. При совместном обсуждении следует явно писать «алгебраическая граница» и «граничное множество вершин» либо «выделенное множество вершин».

## Формы и полиформы

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Форма | formal form | PMG | Формальный символ $[X,Y]$ с соотношениями билинейности или линейная комбинация таких символов одного грейда. |
| Билинейная форма в алгебре PMG | formal bilinear form | С оговоркой | Символ $[X,Y]$ билинеен по внешним аргументам. Он не является числом или уже заданной числовой билинейной функцией на $V$. |
| Квадратичная форма | quadratic form | С оговоркой | Формальный объект $[X]^2=[X,X]$. Его численная оценка определяется отдельно. |
| Транспонирование формы | transpose of a form | С оговоркой | Операция $[X,Y]^{\mathsf T}=[Y,X]$ с линейным продолжением. |
| Полярная форма | polar form | С оговоркой | Ненормированная сумма $\{X,Y\}=[X,Y]+[Y,X]$. Множитель $1/2$ в определение не входит. |
| Антисимметричная форма | skew-symmetric form | С оговоркой | Форма $F$, для которой $F^{\mathsf T}=-F$. Симметричная метрическая оценка такой формы равна нулю. Направленная оценка балграфа может быть ненулевой. |
| Полиформа | polyform in PMG | PMG | Конечная линейная комбинация форм, в том числе разных грейдов. После определения допустимо английское сокращение polyform. |
| Однородная полиформа | homogeneous polyform | С оговоркой | Полиформа одного грейда. |
| Грейд-компонента | grade component | С оговоркой | Однородная компонента $P_k$ заданной полиформы. Допустимое название: «грейд-полиформа». |
| Произведение форм | polyform product | PMG | Операция $[X,Y][A,B]=[XA,YB]$. Коммутативна и отличается от матричного умножения. |
| Единичная форма | unit form | PMG | Форма $e=[1,1]$ грейда $0$, нейтральная относительно произведения форм. |
| Форма на границах | form on boundaries | PMG | Форма с аргументами из $\Lambda^kW$. Такие формы образуют подалгебру, на которой определена метрическая оценка ядра. |
| Нильпотентность | nilpotency | Стандартный | Равенство некоторой положительной степени элемента нулю. Например, $([v]^2)^2=0$ для вектора $v$; сама форма ненулевого вектора ненулевая. |

В электрической части вводной серии выражение «квадратичная форма лапласиана» также обозначает числовую функцию $\varphi\mapsto\varphi^{\mathsf T}\mathbf L\varphi$. При совместном использовании с формальной полиформой $L$ необходимо указывать, о каком представлении идёт речь.

## Структурные тождества и симметрические полиформы

Определения опираются на [[Формы разбиений и тождество тетраэдра]] и [[Симметрические полиформы - типы и нормировки]]. Они относятся к формальной алгебре и не требуют выбора метрики.

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Форма разбиения | partition form | PMG | Для разбиения $\pi$ на блоки $B_1,\ldots,B_m$ это $q_\pi=[(B_1)\cdots(B_m)]^2$. Грейд равен $n-m$, где $n$ — число вершин. Одноэлементный блок даёт единичный множитель. |
| Структурное тождество | structural identity | PMG | Линейное соотношение между формами разбиений фиксированного множества вершин, выполняющееся в формальной алгебре. Численное равенство в одной выбранной метрике само по себе таким тождеством не является. |
| Полный тип формы разбиения | full type of a partition form | PMG | Набор грейдов границ блоков $\lambda=[\#B_1-1,\ldots,\#B_m-1]$. Если положительных частей $r$, а нулевых $\ell$, то $m=r+\ell=n-k$, где $k$ — сумма частей. Нули можно опускать при фиксированном $n$. Тип относится к разбиению и выбранному представлению суммы. |
| Симметрическая полиформа; СПФ | symmetric polyform; SPF | PMG | Полиформа, инвариантная относительно всех перестановок заданного множества базовых вершин. Симметрия по вершинам отличается от симметрии формы по двум аргументам. |
| Симметрическая сумма заданного типа | symmetric sum of a given type | PMG | $E_n[\lambda]$ — сумма форм $q_\pi$ по всем разбиениям заданного множества из $n$ вершин с полным типом $\lambda$. Каждое разбиение входит один раз с коэффициентом $1$. |
| Главная симметрическая полиформа; ГСПФ | principal symmetric polyform; principal SPF | PMG | $E_n[k]$ при $1\leqslant k\leqslant n-1$: сумма по одному блоку из $k+1$ вершин, остальные блоки одноэлементные. Грейд $0$ задаётся отдельно: $E_n[0^n]=e$. |
| Размер представления полиформы | size of a polyform representation; representation size | PMG | Количество слагаемых в выбранной записи суммы форм с коэффициентами. В базовой нормировке $\#E_n[\lambda]$ равно числу индексирующих разбиений. Не является размерностью линейного пространства или инвариантом полиформы. |

В лесу блоки разбиения задаются компонентами связности. Компонента из $b$ вершин имеет $b-1$ рёбер, поэтому число её рёбер совпадает с грейдом границы. Несколько деревьев на одном блоке дают одну форму разбиения. Размер симметрической суммы и число лесов поэтому вычисляются отдельно; разбор приведён в [[Комбинаторные потенциалы в симметрических полиформах]].

## Комбинаторные потенциалы и лесные коэффициенты

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Комбинаторный потенциал второго рода | combinatorial potential of the second kind | PMG | $s_2(\mathbf x)$ — число разбиений множества из $w(\mathbf x)$ различимых элементов на неупорядоченные блоки с положительными размерами $\mathbf x$. Термин PMG для этого комбинаторного числа. [[Разбиения и комбинаторный потенциал второго рода]]. |
| Внешний комбинаторный потенциал | external combinatorial potential | PMG | $e_n(\mathbf x)=\binom{n}{w(\mathbf x)}s_2(\mathbf x)$ при $w(\mathbf x)\leqslant n$: выбор подмножества заданного размера и его разбиения заданного типа. Индексированная функция $e_n$ отличается от единичной формы $e$. [[Комбинаторные потенциалы в симметрических полиформах]]. |
| Лесные коэффициенты | forest coefficients | PMG | Числа $\operatorname{St}(k,m)$, считающие леса на $k$ различимых обычных вершинах и $m$ добавленных непронумерованных корнях: в каждой компоненте ровно один корень, изолированных корней нет. Здесь $m$ относится к вспомогательной конструкции, а не ко всем компонентам исходного графа на $n$ вершинах. Отличаются от $\tau(G)$ и обычных чисел Стирлинга $S(k,m)$. [[Лесные коэффициенты и многочлены Абеля]]. |
| $r$-числа Стирлинга второго рода | $r$-Stirling numbers of the second kind | Стандартный | $\left\{\begin{smallmatrix}N\\K\end{smallmatrix}\right\}_r$ — число разбиений $N$ элементов на $K$ непустых блоков, в которых $r$ заданных различных элементов лежат в разных блоках. Здесь $N,K$ — полные размеры; сдвинутая запись $c_r(w,m)$ означает $N=w+r$, $K=m+r$. [[Убывающие факториалы, корневые леса и числа Стирлинга]]. |

Для $\mathbf x=[x_i]$ с положительными целыми частями, $w=w(\mathbf x)$ и набором кратностей $\boldsymbol\mu=[\mu_j]_{j\in J}$ формула имеет вид

$$
s_2(\mathbf x)=\frac{w!}{[x_i!]!\,[\mu_j!]!}
$$

Комбинаторный потенциал считает разбиения и не использует метрику. Потенциал формы $u_M(f)=\tau(Mf)$ определяется в другом смысле, через метрическую полиформу. При применении $s_2$ необходимо указывать, что задают части аргумента: размеры блоков вершин или части вспомогательного разбиения. Например, $\#E_5[2,1]=s_2([3,2])=10$, тогда как коэффициент в $E_5[2,1]=3E_5[3]$ равен $s_2([2,1])=3$. Соответствующих лесов в $K_5$ — $30$.

Связь лесных коэффициентов с $r$-числами используется здесь для конкретных подсчётов PMG. Общая классификация семейств чисел Стирлинга относится к отдельному проекту по комбинаторике и алгебре разбиений.

## Топономы разбиений и операции над типами

Определения и границы операций изложены в серии [[Топономы разбиений]]. Названия собственных конструкций PMG относятся к указанным ниже объектам; они не задают общего названия для любой редукции полиформы.

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Положительный тип формы разбиения | positive type of a partition form | PMG | Полный тип с опущенными нулевыми частями: $\lambda=(k_1,\ldots,k_r)$, $k_i\geqslant1$. При $k=w(\lambda)$ и известном $n$ восстанавливаются $m=n-k$ и $\ell=n-k-r$. Пустой тип обозначается $1$ и соответствует единичной форме $e$. [[От полиформ к разбиениям]]. |
| Топоном разбиений; топоном выбранного представления | partition toponome; toponome of a chosen representation | PMG | Для записи $\mathcal E=\sum_\pi c_\pi q_\pi$ это $T_{\mathcal E}=\sum_\pi c_\pi\lambda(\pi)$. Метки вершин забываются, вклады одинаковых положительных типов складываются. Структурные тождества не обязаны сохраняться; топоном не объявляется инвариантом произвольной записи одной полиформы. [[Топономы и структурные тождества]]. |
| Частичное сопоставление компонент | partial matching of components | Стандартный | Набор пар вхождений частей двух множителей, в котором каждое вхождение участвует не более чем в одной паре. Равные части временно различаются; коэффициент считает сопоставления, дающие один итоговый тип. [[Алгебра второго рода на разбиениях]]. |
| Алгебра второго рода на разбиениях | the second-kind algebra on partitions | PMG | Вещественная алгебра конечных линейных комбинаций числовых разбиений с произведением $*$: сопоставленные части складываются, остальные сохраняются, затем суммируются все частичные сопоставления. Единица - пустой тип $1$. «Второго рода» относится к алгебре; $(1)^k=\sum_{\lambda\vdash k}s_2(\lambda)\lambda$. Изоморфна стандартной алгебре симметрических функций в базисе augmented monomial symmetric functions. |
| Цветовой класс | color class | Стандартный | Множество вершин одного цвета в правильной раскраске; это независимый блок. Весовой тип цветовых классов записывает суммы весов вершин каждого блока. Сумма таких типов отличается от топонома остовных лесов. [[Раскраски графов и произведение разбиений]]. |
| Сумма частичных склеек по выбранным корням | sum of partial gluings at chosen roots | PMG | Граничная реализация $*$: в каждой нетривиальной компоненте заранее выбирается корень, а для каждой сопоставленной пары корни отождествляются без добавления ребра. Суммирование идёт по сопоставлениям, не по выборам корней. Каждая компонента участвует не более чем в одной паре. [[Произведение разбиений и граничные формы]]. |
| Коэффициентная таблица топонома | coefficient table of a toponome | PMG | $\mathcal A_{\mathcal E}=(a_{k,r})$, где $a_{k,r}$ - сумма коэффициентов типов веса $k$ с $r$ положительными частями. Отдельные типы внутри одной ячейки утрачиваются. При сравнении графов число вершин $n$ сохраняется отдельно; данные $(n,\mathcal A_G)$ в общем случае не определяют граф с точностью до изоморфизма. [[Коэффициентные таблицы топономов]]. |
| Коэффициентный треугольник | coefficient triangle | PMG | Расположение таблицы с весом $k$ по столбцам и числом нетривиальных компонент $r$ по строкам. Для непустых типов на $n$ вершинах $r\leqslant k\leqslant n-r$; длины допустимых строк уменьшаются на два. Единичный член учитывается отдельно, нулевые ячейки оставляются пустыми. Конкретный граф может заполнять лишь часть допустимых ячеек. |

В этой серии самостоятельные типы записываются в круглых скобках: $(1^2)=(1,1)$, тогда как $(1)^2=(1)*(1)$ обозначает произведение. Квадратные скобки наборов и запись СПФ $E_n[\lambda]$ сохраняются. Числовые части типа отличаются от вершинных меток в записи границы $(ab)$.

Соответствие $\lambda=(k_1,\ldots,k_r)\leftrightarrow x_{k_1}\cdots x_{k_r}$ сохраняет тип и задаёт две записи одних данных. Обычное умножение этих мономов соединяет списки частей и отличается от $*$. Для непересекающегося объединения графов топономы остовных лесов перемножаются обычным полиномиальным произведением, а суммы типов цветовых классов - произведением $*$.

В топономе графа фиксируется раскрытие факторов экспоненты лапласиана. При единичных весах коэффициенты считают леса; при числовых весах складываются произведения весов их рёбер. Корневое взвешивание компонент, дальнейшие специализации, спектр оператора и его полное спектральное представление требуют собственных определений. Редукция по типам не отождествляется с редукцией одной полиформы другой полиформой.

## Граф, связи и матричные представления

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Коэффициент связи | coupling coefficient | PMG | Парный коэффициент $c_{ij}$. В основной модели он симметричен и неотрицателен. |
| Проводимость ребра | edge conductance | Стандартный | Электрический смысл положительного коэффициента $c_{ij}$. Английское conductivity здесь не используется. |
| Вес ребра | edge weight | Стандартный | Общее название числового параметра ребра. В данной модели вес интерпретируется как проводимость, а не как длина. |
| Взвешенная степень вершины | weighted degree | Стандартный | Сумма $d_i=\sum_jc_{ij}$. |
| Собственное сопротивление ребра | edge resistance | Стандартный | Величина $1/c_{ij}$ для существующего ребра. Может отличаться от резистенса той же пары. Обозначение $r_{ij}$ закреплено за односторонним резистенсом. |
| Матрица лапласиана | graph Laplacian matrix | Стандартный | В симметричной модели матрица $\mathbf L$ с диагональю $d_i$ и внедиагональными элементами $-c_{ij}$. Для орграфа используется исходящий вариант $L_{ii}=\sum_jf_{ij}$, $L_{ij}=-f_{ij}$ при $i\ne j$. |
| Лапласиан; полиформа лапласиана | Laplacian; Laplacian polyform | PMG | Форма первого грейда с коэффициентами матрицы лапласиана. Для ненаправленного графа $L=\sum_{i<j}c_{ij}[a_{ij}]^2$; для балграфа допускается несимметричное билинейное представление на границах. |
| Редуцированный лапласиан | reduced Laplacian | Стандартный | Матрица, полученная удалением строки и столбца одной и той же вершины из $\mathbf L$. |
| Матрица Грина | Green matrix | С оговоркой | $\mathbf{Gr}=\mathbf L^+$. Для связного балграфа обращает лапласиан на подпространстве нулевой суммы и обнуляет постоянные столбцы. При сопряжении «источник - приёмник» грамиан центрированных векторов равен $\mathbf{Gr}^{\mathsf T}$; в симметричном случае это сама $\mathbf{Gr}$. |
| Резистивная матрица | resistance matrix | С оговоркой | Симметричная матрица $\mathbf R=(R_{ij})$ попарных резистенсов. Для балграфа $R_{ij}=r_{ij}+r_{ji}$; отличать от матрицы односторонних резистенсов $\mathbf r$. |
| Дистанционный оператор | distance operator | С оговоркой | Линейный оператор $\mathcal D(A)_{ij}=A_{ii}+A_{jj}-2A_{ij}$ на симметричных матрицах. Для симметричного грамиана даёт квадраты расстояний. У несимметричного грамиана используется сумма $A_{ij}+A_{ji}$ вместо $2A_{ij}$. |
| Центрирующий проектор | centering matrix; centering projector | Стандартный | Матрица $\mathbf J=I-\mathbf1\mathbf1^{\mathsf T}/n$. |
| Центроид | centroid | Стандартный | Среднее точек с одинаковыми весами: $n^{-1}\sum_i a_i$. |
| Центрирование | centering | Стандартный | Выбор центроида началом отсчёта в евклидовой реализации; сумма радиус-векторов становится нулевой. Это не новое линейное соотношение между формальными базовыми вершинами. |

При одновременном использовании представлений за полиформой сохраняется обычная буква, а матрица выделяется полужирным начертанием: $L$ и $\mathbf L$. Скалярные элементы матриц не выделяются жирным: $L_{ij}$, $\mathrm{Gr}_{ij}$. Если матричное представление однозначно, во вводных заметках допускаются обычные буквы $L,G,R$.

## Гриниан и взаимная дуальность

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Векторная форма первого грейда | grade-one vector form | PMG | В симметричном случае сумма квадратичных форм векторов из $W$: $\sum c_\ell[u_\ell]^2$. Лапласиан и гриниан имеют каноническую запись через $[a_{ij}]^2$. Коэффициенты могут иметь разные знаки. |
| Граничная полиформа | boundary polyform | PMG | Полиформа, аргументы форм которой принадлежат внешним степеням пространства векторов $W$. Экспоненты лапласиана и гриниана относятся к этому типу; их высшие грейды содержат внешние произведения нескольких векторов. |
| Гриниан | Greenian | PMG | Форма первого грейда $\mathrm{Gr}=\sum_{i,j}\mathrm{Gr}_{ij}[a_i-h,a_j-h]$ с матрицей Грина $\mathbf{Gr}=\mathbf L^+$. В симметричном случае $\mathrm{Gr}=-\sum_{i<j}\mathrm{Gr}_{ij}[a_{ij}]^2$. Прежнее название - «полиформа Грина». Не смешивать с грамианом $\mathbf G$. |
| Дуальное представление гриниана | dual representation of the Greenian | PMG | Форма $Q_1$ на $W^*$, для которой $\mathcal C(Q_1)=\mathrm{Gr}$ при $\mathcal C:a_i^\vee\mapsto p_i=a_i-h$: $a_i^\vee$ - дуальный элемент, $a_i$ - прямая вершина. Её экспонента $D=\exp Q_1$ имеет нулевой грейд $e$. В дуальной записи $\sum_i a_i^\vee=0$; в разделах об одном пространстве знак $\vee$ можно опускать по явному соглашению. |
| Взаимно-дуальные экспоненты | mutually dual exponentials | PMG | При невырожденных симметричных первых грейдах: $M_d/Q_k=M_{d-k}$ и $Q_d/M_k=Q_{d-k}$ в согласованных прямом и двойственном пространствах. Знак $/$ означает внешнее удаление. Это отношение, а не отдельный тип полиформ и не мультипликативная обратимость. |

Соглашения и доказательства приведены в [[Лапласиан и гриниан - взаимная дуальность экспонент]] и [[Каноническое векторное представление гриниана]]. В данной серии прежнее название «дуальная полиформа» для $D$ заменяется на «экспонента гриниана в дуальном представлении». При обсуждении самого отношения выражение «полиформа, дуальная к заданной» сохраняет точный смысл. Симметричный квадратичный случай не отождествляется с общим билинейным случаем балграфов.

## Резистивная геометрия и метрическая оценка

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Эффективное сопротивление | effective resistance | Стандартный | Величина $R_{ij}$, определённая всей сетью и парой вершин. В резистивном представлении равна квадрату евклидова расстояния. |
| Резистивное расстояние | resistance distance | Стандартный | Эффективное сопротивление $R_{ij}$ как метрика на вершинах. Не обозначает $\sqrt{R_{ij}}$. |
| Резистивная метрика на векторах | resistance inner product | С оговоркой | В симметричной модели скалярное произведение $u\cdot v=\mathbf u^{\mathsf T}\mathbf{Gr}\mathbf v$ на $W$. В балансовом расширении различаются полное сопряжение $\beta$ и его симметричная часть $g$. |
| Резистивный симплекс | resistance simplex | С оговоркой | Евклидов симплекс, квадраты расстояний между вершинами которого равны $R_{ij}$. В основной модели его размерность равна $n-1$. |
| Матрица Грама; грамиан | Gram matrix | С оговоркой | Матрица $\mathbf G=(g_{ij})$ попарных сопряжений выбранных элементов: $g_{ij}=a_i\cdot a_j$. В балансовой модели порядок ролей - $a_i^{\mathrm{out}}\cdot a_j^{\mathrm{in}}$. Для локальных вершин $\mathbf G=-\mathbf R/2$ в симметричном случае; в общем случае $(\mathbf G+\mathbf G^{\mathsf T})/2=-\mathbf R/2$. |
| Смешанный определитель Грама | mixed Gram determinant | Стандартный | Определитель матрицы $(u_r\cdot v_s)$ для двух упорядоченных наборов одинакового размера. |
| Индуцированное скалярное произведение | induced inner product | Стандартный | Продолжение метрики на $\Lambda^kW$ через смешанный определитель Грама и билинейность. |
| Норма внешнего объекта; квадратичная норма | Norm of an exterior element; quadratic norm | PMG | Число $X^2=X\cdot X$. В резистивной метрике называется также резистивной нормой. Для простого объекта на границах в симметричной метрике равно квадрату объёма параллелотопа; в балансовой модели полный потенциал может содержать циркуляционный вклад. |
| Линейная норма | Linear norm | PMG | Величина $\|X\|=\sqrt{X^2}$ при $X^2\ge0$. На положительно определённом пространстве совпадает с обычной евклидовой нормой. |
| Численная метрическая оценка формы | metric evaluation of a form | PMG | Линейная оценка $[X,Y]\mapsto X\cdot Y$ на формах на границах одного грейда. |

> [!info] Объект, форма и число
> Обозначения $X$, $[X]^2$ и $X^2$ различаются: первое задаёт внешний объект, второе формальную квадратичную форму, третье численную норму. Внешнее произведение объекта с самим собой записывается явно как $X\wedge X$.

В симметричной метрике норма границы симплекса соответствует квадрату объёма параллелотопа, а её линейная норма - самому объёму. Квадрат объёма $k$-мерного симплекса равен норме его границы, делённой на $(k!)^2$. Метрика на границах не задаёт автоматически норму формальной точки или симплекса вне $\Lambda^kW$.

## Метрическая полиформа, леса и остовной коэффициент

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Метрическая полиформа | metric polyform | PMG | Экспонента $M_G=\exp L$ в алгебре форм. Не матричная экспонента $\exp\mathbf L$. |
| Форма связи | edge form; pair form | PMG | Квадратичная форма $[a_{ij}]^2$. Взвешенный вклад в лапласиан равен $c_{ij}[a_{ij}]^2$. |
| Фактор-форма связи | edge factor | PMG | Множитель $e+c_{ij}[a_{ij}]^2$ в факторизации $M_G$. Допустимо сокращение «фактор-форма». |
| Остовное дерево | spanning tree | Стандартный | Связный ациклический подграф, содержащий все вершины исходного графа. |
| Остовной лес | spanning forest | С оговоркой | В этой серии любой ациклический подграф, содержащий все вершины, включая изолированные. Максимальность набора рёбер не требуется. |
| Остовной 2-лес | spanning 2-forest | Стандартный | Остовной лес ровно с двумя компонентами. |
| Разделяющий остовной 2-лес | separating spanning 2-forest | С оговоркой | Остовной 2-лес, в котором две заданные вершины принадлежат разным компонентам. |
| Вес леса или дерева | forest weight; tree weight | Стандартный | Произведение проводимостей выбранных рёбер. Пустое произведение равно $1$. |
| Лесное разложение | forest expansion | С оговоркой | Представление грейда $M_k$ суммой взвешенных форм лесов из $k$ рёбер. Каждый такой лес имеет $n-k$ компонент. |
| Остовная форма | spanning-tree form | PMG | Фиксированная форма $T_n=[(a_1\ldots a_n)]^2$ грейда $n-1$. |
| Предельная форма | top-grade form | PMG | В ядре другое название остовной формы $T_n$. Не означает предельного перехода; перевод limit form не используется. |
| Предельная компонента | top-grade component | С оговоркой | Для связной метрической полиформы компонента $M_{n-1}=\tau(G)T_n$. Её следует отличать от самой формы $T_n$. |
| Допредельная компонента | next-to-top-grade component | PMG | Для связной метрической полиформы компонента $M_{n-2}$, содержащая формы остовных 2-лесов. |
| Остовной коэффициент графа | weighted spanning-tree sum; spanning-tree coefficient | С оговоркой | $\tau(G)$, сумма весов остовных деревьев. При единичных проводимостях это spanning-tree count. |
| Функционал извлечения остовного коэффициента | top-coefficient functional | PMG | Линейный функционал $\tau(P)$, извлекающий коэффициент при фиксированной $T_n$ из полиформы на границах. Для произвольного $P$ это не обязательно сумма весов деревьев. |

В несвязном графе старший ненулевой грейд $M_G$ равен $n-c$, где $c$ есть число компонент связности. Термин «старшая ненулевая компонента» не означает замену фиксированной $T_n$ другой формой: при $c>1$ по-прежнему $\tau(M_G)=0$.

Сумма лесных весов относится к заданному лесному разложению. Из-за линейных соотношений между формами сумма коэффициентов произвольной записи того же объекта может быть иной.

## Потенциалы, нормы и вариации

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
|---|---|---|---|
| Электрический потенциал вершины | electrical potential | Стандартный | Значение $\varphi_i$ в решении уравнений сети при заданном воздействии. Определяется с учётом свободы выбора отсчёта. |
| Потенциал формы | polyform potential | PMG | $u_M(f)=\tau(Mf)$ при фиксированной метрической полиформе $M$. Не электрический потенциал вершины. |
| Нормированный потенциал | normalized polyform potential | PMG | $P_M(f)=u_M(f)/u_M(e)=\tau(Mf)/\tau(M)$ при $\tau(M)\ne0$. Одно определение применяется в симметричной и балансовой моделях. |
| Норма формы в PMG | PMG form norm | PMG | Допустимое название нормированного потенциала. Для общей формы это линейная оценка, а не норма в обычном смысле. |
| Метрическое тождество | metric identity | PMG | В симметричной модели нормированный потенциал $[X,Y]$ равен индуцированному скалярному произведению $X\cdot Y$. В балансовой модели используется полное сопряжение $\beta$ и его определительное продолжение, а не только симметричная часть $g$. |
| Вариация проводимости | conductance variation | Стандартный | Изменение $c_{ij}\mapsto c_{ij}+t$. В основной графовой модели требуется неотрицательность конечной проводимости. |
| Алгебраическая вариация лапласиана | algebraic Laplacian variation | PMG | В симметричной модели элементарная поправка $t[v]^2$ при $v\in W$; в балансовой - $t[u,v]$ при $u,v\in W$. В общем случае меняет несколько связей; допустимость весов проверяется отдельно. |
| Совместная вариация связей | joint conductance variation | С оговоркой | Одновременное изменение проводимостей нескольких пар вершин; их взаимодействие определяется грамианом соответствующих векторов. |

В симметричной резистивной модели для квадратичной формы $[X]^2$ нормированный потенциал равен $\|X\|^2$, а не $\|X\|$. Для смешанной формы он может быть отрицательным даже при положительно определённой метрике. Это не означает отрицательной нормы внешнего объекта.

В PMG слово «норма» без уточнения «линейная» означает квадратичную норму $X^2=X\cdot X$. Обозначение $\|X\|$ сохраняется за линейной нормой. Норма формы определяется через нормированный потенциал; численная оценка произведения форм в общем случае не равна произведению их оценок.

## Балансовые графы и направленная метрика

Здесь рассматриваются балграфы без петель с неотрицательными весами дуг. Для нормировки потенциалов и метрики предполагается связность. Соглашения собраны в [[Спецификация ядра PMG#Балансовое расширение|балансовом расширении спецификации]]; доказательства находятся в серии [[Балансовые графы]].

| Русский термин | Английское соответствие | Статус | Значение и соглашение |
| --- | --- | --- | --- |
| Балансовый граф; балграф | balanced digraph; balanced graph | Стандартный; сокращение PMG | Взвешенный орграф с равенством сумм входящих и исходящих весов в каждой вершине. Для исходящего лапласиана $\mathbf L\mathbf1=0$ и $\mathbf1^{\mathsf T}\mathbf L=0$. |
| 2-балграф | 2-balanced graph | PMG | Условное название симметричного графа как суммы взвешенных 2-орциклов. Возможность такого разложения не означает, что все его разложения состоят только из 2-орциклов. |
| Вес дуги | arc weight | Стандартный | $f_{ij}\ge0$ для дуги $i\to j$; $L_{ij}=-f_{ij}$ при $i\ne j$. Не является направленным скалярным произведением вершин. |
| Остовное ордерево к корню | spanning in-arborescence | Стандартный | Направленное остовное дерево, в котором из каждой некорневой вершины выходит ровно одна дуга и путь ведёт к корню. |
| Остовной потенциал вершины | rooted spanning-tree potential | С оговоркой | $\tau_i=\det\mathbf L_{\widehat i,\widehat i}$, сумма весов ордеревьев к корню $i$. Столбец удовлетворяет $\mathbf L^{\mathsf T}\boldsymbol\tau=0$. Не электрический потенциал $\varphi_i$. |
| Общий остовной коэффициент балграфа | common spanning-tree coefficient | С оговоркой | Общее значение $\tau_i=\tau>0$ в связном балграфе. Считается один фиксированный корень; сумма по всем корням равна $n\tau$. [[Балансовые графы и остовные потенциалы]]. |
| Каноническое центрированное представление | canonical centered representation | PMG | $L=\sum_{i,j}L_{ij}[a_i-h,a_j-h]$ при центроиде $h$. Матрица коэффициентов нормирована нулевыми суммами строк и столбцов. Это не каноническое разложение на орциклы. [[Билинейный лапласиан балграфа]]. |
| Направленное сопряжение; направленное скалярное произведение | directional pairing; bilinear pairing | С оговоркой | $\beta(u,v)=P_M([u,v])=\mathbf v^{\mathsf T}\mathbf{Gr}\mathbf u$. Первый аргумент имеет роль источника $\mathrm{out}$, второй - приёмника $\mathrm{in}$. В общем случае не является симметричным inner product. |
| Симметричная часть метрики | symmetric part of the metric | С оговоркой | $g(u,v)=(\beta(u,v)+\beta(v,u))/2$. Положительно определена на $W$ и задаёт евклидовы расстояния с квадратами $R_{ij}$. Не определяет всю билинейную метрику. |
| Форма циркуляции | circulation form | PMG | $\omega(u,v)=[u,v]-[v,u]$ для аффинных векторов. Антисимметричная формальная форма первого грейда PMG. Может рассматриваться без графа. [[Форма циркуляции]]. |
| Треугольная форма циркуляции | triangular circulation form | PMG | $w(abc)=\omega(b-a,c-a)$. В принятой ориентации $w(abc)=L_{acb}-L_{abc}$ для единичных орциклов. Это разность, а не полный лапласиан орцикла. |
| Циркуляционный потенциал; циркуляционная норма | circulation potential; circulation norm | PMG | $\chi_{ijk}=P_M(w(a_i a_j a_k))$. Равен разности сумм односторонних резистенсов по двум обходам. Может иметь знак; слово «норма» означает нормированный потенциал формы. |
| Односторонний резистенс | one-way resistance | PMG | $r_{ij}=P_M([a_j-h,a_j-a_i])=\mathrm{Gr}_{jj}-\mathrm{Gr}_{ij}$. Определён для любой пары и может быть несимметричным даже в ненаправленном графе. [[Односторонний резистенс и время достижения]]. |
| Двусторонний резистенс | two-way resistance | С оговоркой | $R_{ij}=r_{ij}+r_{ji}$. Совпадает с резистенсом ненаправленного графа в симметричном случае. |
| Матрица односторонних резистенсов | one-way resistance matrix | PMG | $\mathbf r=(r_{ij})$. Определяет $\mathbf{Gr}=-\mathbf J\mathbf r$ и исходный $\mathbf L=\mathbf{Gr}^{+}$. Симметричная $\mathbf R=\mathbf r+\mathbf r^{\mathsf T}$ в общем случае недостаточна. |
| Матрица средних времён достижения | mean hitting-time matrix | Стандартный | $\mathbf H=(H_{ij})$ в выбранной марковской модели. Для непрерывного блуждания с генератором $-\mathbf L$ связного балграфа $H_{ij}=nr_{ij}$. Это интерпретация резистенсов; для другой нормировки процесса формула меняется. |
| Исходящие и входящие би-координаты | outgoing and incoming bi-coordinates | PMG | Коэффициенты разложения заданного представителя в базисе роли $\mathrm{out}$ или $\mathrm{in}$. Разложение в каждой роли единственно. Два представителя одного функционала могут иметь разные координаты. |
| Исходящие и входящие ди-координаты | outgoing and incoming di-coordinates | PMG | Сопряжения с базисом противоположной роли: $\mathbf d_{\mathrm{out}}=\mathbf G^{\mathsf T}\mathbf b_{\mathrm{out}}$, $\mathbf d_{\mathrm{in}}=\mathbf G\mathbf b_{\mathrm{in}}$. [[Грамиан и направленные координаты балграфа]]. |
| Направленные проекции | directional projections | PMG | Проекции с условием ортогональности в первом или втором аргументе $\beta$. Для прямой $ab$ их коэффициенты при $b$ равны $\beta(a_i-a,b-a)/R_{ab}$ и $\beta(b-a,a_i-a)/R_{ab}$. [[Балансовые вариации#Односторонняя вариация и нарушение баланса]]. |
| Метрические представители сферы | metric representatives of the sphere | PMG | $S_{\mathrm{out}}$ и $S_{\mathrm{in}}$ представляют один функционал через сопряжения с разных сторон. Их би-координаты могут различаться, но $S_{\mathrm{out}}\cdot S_{\mathrm{in}}=\rho$. [[Изотропное пространство и сфера балграфа]]. |
| Балансовая вариация | balanced variation | С оговоркой | Изменение лапласиана с нулевыми суммами строк и столбцов; неотрицательность итоговых весов проверяется отдельно. Элементарный вид - $t[u,v]$ при $u,v\in W$. [[Балансовые вариации]]. |
| Односторонняя вариация дуги | single-arc variation | С оговоркой | Изменение веса одной дуги $a\to b$, $\Delta\mathbf L=t\mathbf e_a(\mathbf e_a-\mathbf e_b)^{\mathsf T}$. При $a\ne b$ и $t\ne0$ нарушает баланс исходного балграфа. |

Индексы $i\to j$ у $r_{ij}$ задают направление пары, а роли $\mathrm{out}/\mathrm{in}$ - порядок аргументов сопряжения; это разные соглашения. Нормированный потенциал $P_M(F)=\tau(MF)/\tau(M)$ является общей алгебраической основой резистивных и циркуляционных величин. Остовные потенциалы вершин $\tau_i$ и электрические потенциалы $\varphi_i$ определяются отдельно.

## Прежние названия и неоднозначные употребления

| Прежнее или неоднозначное название | Рекомендуемая запись | Причина уточнения |
|---|---|---|
| «Метрическая масса» | «Резистивный радиус», если параметр равен $R_{\mathrm{sph}}^2$; «резистивный диаметр», если он равен $4R_{\mathrm{sph}}^2$ | Прежнее название заменено геометрическим с явным различением нормировок. |
| «2-вектор» | «вектор пары вершин», $a_{ij}=a_j-a_i$ | Английское 2-vector обычно означает объект второго внешнего грейда, тогда как $a_{ij}$ имеет грейд $1$. «Двухточечный вектор» допустим как явно определённый синоним. |
| «Порядок» без указания объекта | «грейд» | Грейд симплекса и грейд его границы различаются на единицу. |
| «Кратность» линейного элемента | «аффинный вес» | Значение функционала суммы коэффициентов не обязано быть целым. |
| «Остовное число» взвешенного графа | «остовной коэффициент» | Взвешенная сумма не обязательно целочисленна. Для числа деревьев допустимо «число остовных деревьев». |
| «Резистенс» | «резистенс»; в электрической интерпретации «эффективное сопротивление» | В обычном графе используется геометрическое название. Электрический термин поясняет соответствующую интерпретацию и сопоставление с внешними источниками. |
| «Матрица резистенсов» | «резистивная матрица» | Единое название с вводной серией. |
| «Двухлес» | «остовной 2-лес» | Полное название указывает охват всех вершин и число компонент. |
| «Связь-форма» | Явно указать $[a_{ij}]^2$, $c_{ij}[a_{ij}]^2$ или $e+c_{ij}[a_{ij}]^2$ | Форма пары, вклад в лапласиан и фактор экспоненты являются разными объектами. |
| «Квадрат нормы» для $X\cdot X$ | «Норма», «квадратичная норма»; в резистивной метрике также «резистивная норма» | В PMG нормой называется само число $X\cdot X$; его корень при неотрицательной норме называется линейной нормой. Формальная форма $[X]^2$ отличается от её численной оценки. |
| «Потенциал объекта» | «потенциал формы $f$» или «комбинаторный потенциал набора $\mathbf x$» — по смыслу | Для $u_M(f)$ указать форму и метрику; для $s_2(\mathbf x)$ или $e_n(\mathbf x)$ — набор и считаемые разбиения. |
| «Независимые компоненты» в произведении границ | «произведение границ компонент» | Раздельная запись множителей сама по себе не означает метрической ортогональности или статистической независимости. |
| «Коммутатор формы» | Антисимметричная разность $[X,Y]-[Y,X]$; для аффинных векторов - форма циркуляции $\omega(u,v)$ | Историческое название PMG не совпадает с операторным коммутатором $AB-BA$. Принятая нормировка циркуляции не содержит множителя $1/2$. |

## Термины расширений

Следующие определения используются в опубликованной серии «Пространства и подпространства в PMG». Они дополняют справочник; обязательные определения ядра остаются в [[Спецификация ядра PMG|спецификации]]. Условия и примеры приведены в связанных заметках.

| Термин | Английское соответствие | Значение и источник |
| --- | --- | --- |
| Фрейм объекта | Frame of an object | Представление объекта линейной комбинацией выбранных элементов, включая сами элементы и коэффициенты. Набор может быть зависимым; разные фреймы могут представлять один объект. [[Проекции, би-координаты и ди-координаты#Би-координаты и фреймы]]. |
| Би-координаты | Bi-coordinates | Коэффициенты единственного разложения объекта в выбранном базисе соответствующего линейного пространства. Точечный базис не обязателен; барицентрические координаты точек являются частным случаем. [[Проекции, би-координаты и ди-координаты#Би-координаты и фреймы]]. |
| Матрица би-координат | Bi-coordinate matrix | Матрица $\mathbf B$ коэффициентов разложения выбранных объектов по указанному базису. При её определении нужно указать, расположены ли координаты объектов в строках или столбцах. Матрица влияния является частным случаем. |
| Расширенный изотропный грамиан | Extended isotropic Gram matrix | Матрица $\mathbf G_z=G(a_1,\ldots,a_n,z)$ для локальных вершин и нуль-вектора. В порядке, где $z$ стоит последним, это блоки $\left(\begin{smallmatrix}\mathbf G&\mathbf1\\\mathbf1^{\mathsf T}&0\end{smallmatrix}\right)$. [[Нуль-вектор, изотропное представление и граница#Грамиан вершин и расширенный грамиан]]. |
| Ди-координаты | Di-coordinates | Скалярные произведения объекта с элементами выбранного базиса. При невырожденной метрике на его подпространстве это также коэффициенты проекции во взаимном базисе. [[Проекции, би-координаты и ди-координаты#Ди-координаты: скалярные произведения]]. |
| Взаимный базис | Reciprocal basis | Базис того же подпространства, скалярные произведения элементов которого с элементами исходного базиса равны $1$ при совпадении номеров и $0$ иначе. Существует при невырожденной метрике на подпространстве. [[Проекции, би-координаты и ди-координаты#Взаимный базис]]. |
| Лапласиан фрейма | Laplacian of a frame | Разностная часть разложения формы фиксированного фрейма: $L_q=\sum_{i<j}q^iq^j[a_j-a_i]^2$. При замене фрейма может измениться; не определяется одним объектом $q$. [[Проекции, би-координаты и ди-координаты#Разностная часть и лапласиан фрейма]]. |
| Локальный элемент; локальная точка | Local element; local point | Элемент единичного аффинного веса и нулевой нормы: $x\cdot z=1$, $x^2=0$. В изотропной модели представляет точку. [[Нуль-вектор, изотропное представление и граница#Локальные точки]]. |
| Нелокальный элемент единичного веса | Nonlocal element of unit weight | Элемент $p$ с $p\cdot z=1$ и $p^2\ne0$. Термин PMG в изотропной модели. [[Нелокальные элементы, сферы и их центры#Разложение элемента на центр и норму]]. |
| Локальный центр | Local center | Точка $\pi(p)=p-p^2z/2$ для $p\cdot z=1$. Выделение центра является нелинейной поправкой вдоль $z$. [[Нелокальные элементы, сферы и их центры#Разложение элемента на центр и норму]]. |
| Элемент сферы | Sphere element | В симметричном изотропном пространстве $S=h+\rho z/2$, где здесь $h$ - локальный центр; $x\cdot S=0$ задаёт локальные точки сферы и $S^2=\rho$. [[Нелокальные элементы, сферы и их центры#Сфера как условие ортогональности]]. В балграфе один функционал сферы имеет два метрических представителя. [[Изотропное пространство и сфера балграфа]]. |
| Выделенный нуль-вектор | Distinguished null vector | Ненулевой элемент $z$ с $z^2=0$, задающий нормировку локальных точек. Нуль-вектор не является нулевым элементом пространства. [[Нуль-вектор, изотропное представление и граница]]. |
| Изотропный элемент | Isotropic element | Ненулевой линейный элемент $u$ с нулевой нормой $u\cdot u=0$, независимо от аффинного веса. Локальные элементы изотропны; нуль-вектор $z$ изотропен, но не локален, поскольку имеет вес $0$. [[Нуль-вектор, изотропное представление и граница]]. |
| Метрический квадрат | Metric square | Прежнее поясняющее название нормы $Y^2=Y\cdot Y$. В текущем изложении используется «норма». В неопределённой метрике она может быть отрицательной. Отличается от формы $[Y]^2$. |
| Орбиталь относительно расширенного базиса | Orbital relative to the chosen extended basis | Би-координата при $z$ в заданном расширенном базисе. Не совпадает с ди-координатой $Y\cdot z$. [[Проекции, би-координаты и ди-координаты#Координаты в изотропном расширении]]. |
| Суб-базис | Sub-basis | Выбранная часть полного базиса, порождающая своё подпространство. Объект вне этого подпространства не имеет разложения на суб-базисе, хотя его ди-координаты по этим элементам определены. [[Проекции, би-координаты и ди-координаты#Линейная середина и её локальный центр]]. |
| Резистивный радиус | Resistance radius | Определение PMG через обратный изотропный грамиан: $\rho=(\mathbf G_z^{-1})_{n+1,n+1}$. В симметричном случае $\rho=R_{\mathrm{sph}}^2$ - квадрат евклидова радиуса описанной сферы. В балграфе он может отличаться от квадрата радиуса евклидовой реализации симметричной части метрики. [[Изотропное пространство и сфера балграфа]]. |
| Резистивный диаметр | Resistance diameter | $D_{\mathrm{res}}=4\rho$. В симметричном случае равен квадрату линейного диаметра описанной сферы. В балансовой модели сохраняется алгебраическая нормировка через $\rho$; в общем случае не максимальный попарный резистенс. [[Стягивание вершин и сочленение графов#Резистивный радиус складывается]]. |
| Матрица влияния | Influence matrix | Матрица $\mathbf B$ коэффициентов продолжения значений с выбранных вершин на внутренние. Её строки дают би-координаты проекций. В балграфе нужно указать, используется $\mathbf L$ или $\mathbf L^{\mathsf T}$. [[Выделенные вершины и задача Дирихле]]. |
| Фундаментальная матрица | Fundamental matrix | $\mathbf{Fm}=\mathbf A^{-1}$, где $\mathbf A$ есть внутренний блок лапласиана. Для связного неориентированного графа это также матрица Грама векторов отклонений; при несвязности метрическое утверждение применяется по компонентам. Обратимость требует закрепления каждой компоненты выбранными вершинами. [[Выделенные вершины и задача Дирихле]]. |
| Матрица отклика | Response matrix | Матрица $\boldsymbol\Lambda$, переводящая заданные значения на выбранных вершинах в отклик после решения внутренних уравнений. Совпадает с лапласианом наведённого графа. [[Исключение вершин и наведённые связи]]. |
| Общий остовной параметр двух долей | Common spanning-tree parameter of the two parts | Локально введённая нормировка $J(G)$ остовного коэффициента двудольного графа. Вычисляется через любую долю с сохранением её исходных степеней. [[Связи внутри одной доли двудольного графа]]. |

Для других расширений, включая KVP/KVPOU, метрические распределения и интервальные формы, определения и переводы добавляются по мере подготовки соответствующих публичных разделов. Сохраняются ограничения:

- «Коцентр» не используется как синоним центроида или название самостоятельного геометрического центра без отдельного определения.
- Перевод операции «внешнее деление» не фиксируется до её формального сопоставления со стандартными операциями внешней алгебры.
- Термины «дуальность» и «метрическое распределение» требуют определения конкретной конструкции; их смысл не следует из одного названия.

## Правила употребления и история редакций

В русских текстах принята форма «остовной»: «остовной лес», «остовной 2-лес», «остовной коэффициент». Для среднего рода используется «остовное дерево».

При первом употреблении собственного термина PMG приводится определение или точная ссылка на него. Совпадение названия с термином другой области не заменяет определения. Для английского текста при необходимости используются уточнения polyform in PMG, polyform potential и PMG form norm.

В пределах одного вывода необходимо различать граф $G$, грамиан $\mathbf G$ и матрицу Грина $\mathbf{Gr}$, формальные формы и их численные оценки, а также матричное и полиформное умножение. Переименование математического объекта должно сопровождаться указанием соответствия прежнему названию.
