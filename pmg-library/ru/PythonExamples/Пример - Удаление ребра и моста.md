Пример иллюстрирует правило удаления связи из [[Экспонента лапласиана#Добавление и удаление ребра|Экспоненты лапласиана]]. Рассматриваются два случая: удаление ребра $ab$ из единичного $C_4$ и удаление моста $bc$ проводимости 2 из цепочки $a-b-c$ с проводимостями $c_{ab}=1$ и $c_{bc}=2$. Во втором случае граф становится несвязным.

[[en/PythonExamples/Example - Deleting an Edge and a Bridge|English]] · [[ru/PythonExamples/PythonExamples|Программные примеры]]


Пример проверен с `polyform_algebra 0.9.0`. Подготовка окружения: [[Установка библиотеки и запуск примеров]]. Ячейки Python выполняются по порядку.

## Правило удаления

Удаляется существующее ребро целиком, поэтому из его проводимости вычитается именно $c_{ij}$:

$$
p=[a_j-a_i]^2,\qquad M' = M(e-c_{ij}p),\qquad
\tau(M')=\tau(M)(1-c_{ij}R_{ij})
$$
В формуле остовного коэффициента $R_{ij}$ относится к исходной связной сети. Отрицательный коэффициент в факторе удаления допустим в алгебре; итоговая проводимость удаляемого ребра равна нулю. Это не добавление ребра с отрицательной проводимостью.

Из $p^2=0$ следует $(e+cp)(e-cp)=e$. Поэтому повторное добавление удалённой проводимости восстанавливает исходную экспоненту, в том числе после удаления моста.

## Исполняемый фрагмент

```python
import networkx as nx
from polyform_algebra import Polyform, quForm

# Delete edge ab of the unit cycle C4.
graph = nx.cycle_graph(list("abcd"))
laplacian, points = Polyform.from_networkx(graph, return_points="dict")
metric = laplacian.exp()
p = quForm([(points["a"], points["b"])])
updated = metric * (Polyform.one() - p)
print("cycle tau =", updated.potential(quForm.one()))
print("cycle R_ab =", updated.norm(p))

# Delete the bridge of conductance 2, retaining isolated vertex c.
graph = nx.Graph()
graph.add_weighted_edges_from([("a", "b", 1), ("b", "c", 2)])
laplacian, points = Polyform.from_networkx(graph, return_points="dict")
metric = laplacian.exp()
p = quForm([(points["b"], points["c"])])
updated = metric * (Polyform.one() - 2*p)
print("bridge tau =", updated.potential(quForm.one()))
print("remaining exponential =", updated)
f_ac = quForm([(points["a"], points["c"])])
print("unnormalized potential =", updated.potential(f_ac))
try:
    updated.norm(f_ac)
except ValueError as error:
    # Expected: normalization on the full disconnected graph is undefined.
    print(error)
```

## Удаление ребра цикла

После удаления $ab$ остаётся путь $a-d-c-b$. Он содержит все четыре вершины и остаётся связным.

| Величина | До удаления | После удаления |
|---|---:|---:|
| Остовной коэффициент | 4 | 1 |
| Сопротивление $R_{ab}$ | $3/4$ | 3 |
| Старший грейд экспоненты | 3 | 3 |

Равенство $\tau'=4(1-3/4)=1$ согласуется с единственным оставшимся остовным деревом. Между вершинами a и b теперь последовательно соединены три единичных сопротивления.

## Удаление моста

В цепочке $a-b-c$ с $c_{ab}=1$, $c_{bc}=2$ удаляется ребро $bc$. Вершина c становится изолированной, но остаётся частью фиксированного набора вершин:

$$
M=(e+f_{ab})(e+2f_{bc}),\qquad
M'=M(e-2f_{bc})=e+f_{ab}
$$

$$
\tau(M')=0,\qquad u_{M'}(f_{ac})=1
$$
До удаления $\tau=2$ и $R_{bc}=1/2$, поэтому $\tau'=2(1-2\cdot1/2)=0$. Старший ненулевой грейд понижается с 2 до 1. Коэффициент 1 при оставшейся форме $f_{ab}$ нельзя принимать за остовной коэффициент на трёх вершинах: он по-прежнему извлекается при $T_3=[(abc)]^2$ и равен нулю.

Потенциал $u_{M'}(f_{ac})=1$ сохраняет смысл: добавленная форма соединяет компоненты в остов. Но нормировка на $\tau(M')=0$ невозможна. Метод `norm` выдаёт `ValueError`, а не нулевое или конечное сопротивление между компонентами. 

Внутри компоненты $\{a,b\}$ сопротивление физически равно 1. Однако глобальная полиформа несвязного графа не поддерживает нормировку даже для этой пары. Для такого расчёта нужно отдельно построить метрику компоненты. Исходную изолированную вершину нельзя незаметно исключать из глобального контекста.

## Проверки и статус

Шесть математических проверок сравнивают факторное удаление с полным пересчётом по оставшемуся графу, проверяют восстановление ребра, матрицы и их миноры, токовый расчёт для связного случая и отказ нормировки для несвязного. Проверяется также линейное обновление ненормированного потенциала $u_{M'}(f)=u_M(f)-c_{ij}u_M(pf)$.



Это ограничение `Polyform.norm` при глобальной нормировке. Сетевой интерфейс `polyform_algebra.core.resistance` отдельно поддерживает несвязные сети: внутри компонент сопротивления конечны, между компонентами результат обозначается `INFINITY` в точном режиме. Эти два ответа относятся к разным операциям.
