В заметке воспроизводятся примеры усиления связей единичного треугольника из [[Вариация одной связи#Пример: усиление ребра треугольника|Вариации одной связи]] и [[Совместная вариация нескольких связей#Пример: усиление двух связей треугольника|Совместной вариации нескольких связей]]. Основной расчёт выполняется в алгебре квадратичных форм; матричные формулы используются для проверки.

## Исходные объекты

Пусть $a,b,c$ - вершины; для пары $x,y$ обозначим $f_{xy}=[y-x]^2$. Все три проводимости исходного графа $K_3$ равны единице. По определению из [[Экспонента лапласиана]] получаем

$$
L=f_{ab}+f_{ac}+f_{bc},\qquad M=\exp L
$$

```python
from polyform_algebra import Point, Polyform, quForm

a, b, c = Point.create_list("abc")
f_ab = quForm([(a, b)])
f_ac = quForm([(a, c)])
f_bc = quForm([(b, c)])
laplacian = f_ab + f_ac + f_bc
metric = laplacian.exp()

tau = metric.potential(quForm.one())
r_ab = metric.norm(f_ab)
coupling = metric.norm((b-a) @ (c-a))
```

Метод `potential` извлекает коэффициент при фиксированной остовной форме после умножения, а `norm` делит его на $\tau(M)$:

$$
u_M(f)=\tau(Mf),\qquad P_M(f)=\frac{\tau(Mf)}{\tau(M)}
$$

В частности, `tau` равен $3$, `r_ab` равен $2/3$, `coupling` равен $1/3$. Оператор `@` сначала строит скалярную полиформу - половину полярной формы для поддерживаемых аргументов первого грейда. Численное скалярное произведение получается после оценки через `norm`. Потенциал формы не следует смешивать с электрическим потенциалом вершины.

## Усиление одной связи

Увеличим $c_{ab}$ с $1$ до $2$, то есть $\delta=1$. Поскольку $f_{ab}f_{ab}=0$, имеем

$$
\exp(L+\delta f_{ab})=M(e+\delta f_{ab})
$$

```python
delta = 1
after_one = metric * (Polyform.one() + delta*f_ab)
assert after_one.is_equivalent((laplacian + delta*f_ab).exp())

tau_one = after_one.potential(quForm.one())
r_ab_one = after_one.norm(f_ab)
r_ac_one = after_one.norm(f_ac)
probability_ab = (1 + delta)*r_ab_one
forest_ac = after_one.potential(f_ac)
```

| Величина | До изменения | После изменения |
|---|---:|---:|
| $\tau$ | $3$ | $5$ |
| $R_{ab}$ | $2/3$ | $2/5$ |
| $R_{ac}$ | $2/3$ | $3/5$ |
| $R_{bc}$ | $2/3$ | $3/5$ |
| $\Pr(ab\in T)$ | $2/3$ | $4/5$ |
| Вес 2-лесов, разделяющих a и c | $2$ | $3$ |

Вероятность ребра равна $c_{ab}R_{ab}$, поэтому после изменения используется новая проводимость $2$. Ненормированный потенциал `after_one.potential(f_ac)` равен весу соответствующих разделяющих остовных 2-лесов.

Программа также сравнивает результаты с формулами теоретической заметки. При $g=(ab)\cdot (ac)=1/3$

$$
\tau'=\tau(1+\delta R_{ab}),\qquad
R'_{ac}=R_{ac}-\frac{\delta g^2}{1+\delta R_{ab}}
$$

Прирост лесного веса равен $\delta\tau(R_{ab}R_{ac}-g^2)=1$.

## Усиление двух связей

Теперь обе проводимости $c_{ab},c_{ac}$ увеличиваются с $1$ до $2$. Используем исходную метрику $M$ и два множителя:

```python
after_two = metric * (Polyform.one() + f_ab) * (Polyform.one() + f_ac)
assert after_two.is_equivalent((laplacian + f_ab + f_ac).exp())
assert after_two.is_equivalent(
    metric * (Polyform.one() + f_ac) * (Polyform.one() + f_ab)
)

tau_two = after_two.potential(quForm.one())
r_bc_two = after_two.norm(f_bc)
mixed_coefficient = metric.potential(f_ab*f_ac)
```

Ориентируем выбранные векторы от вершины $a$. Для измеряемого вектора $(bc)$ грамиан и столбец взаимодействий равны

$$
\mathbf G=
\begin{pmatrix}2/3&1/3\\1/3&2/3\end{pmatrix},
\qquad
q=\begin{pmatrix}-1/3\\1/3\end{pmatrix}
$$

| Величина | Результат |
|---|---:|
| $\tau$ после первого усиления | $5$ |
| $R_{ac}$ после первого усиления | $3/5$ |
| $\tau$ после обоих усилений | $8$ |
| $R_{bc}$ после обоих усилений | $1/2$ |
| $\det(I_2+\mathbf G)$ | $8/3$ |
| Коэффициент при $\delta_1\delta_2$ в $\tau'$ | $1$ |
| $\Pr(ab,ac\in T)$ в исходной сети | $1/3$ |

Коэффициент совместного действия вычисляется непосредственно как `metric.potential(f_ab*f_ac)` и равен $\tau\det\mathbf G=1$. Численная оценка произведения форм в общем случае не равна произведению их оценок.

Полная программа проверяет формулы

$$
\tau'=\tau\det(I_2+\mathbf G),\qquad
R'_{bc}=R_{bc}-q^{\mathsf T}(I_2+\mathbf G)^{-1}q
$$

Вычисление обратного действия выполняется через `numpy.linalg.solve`. Последовательный расчёт использует обновлённую метрику после первого шага: $5(1+3/5)=8$.

## Независимые проверки и статус

[Тесты примеров](https://github.com/magin67/polyform_algebra/blob/v0.9.0/tests/introductory/test_triangle_variations.py) сверяют числа из заметок, знаки ориентаций, порядок факторов и полный пересчёт экспоненты. Дополнительно матрица лапласиана строится прямо из проводимостей: её минор даёт $\tau$, а решение уравнений токов с заземлённой вершиной $c$ даёт $R_{bc}$. Эта проверка не использует произведения полиформ.



Здесь изменение связей выражается произведениями рёберных факторов. Общие формальные определения приведены в [[Спецификация ядра PMG]], а соглашения об оценке - в [[Терминология PMG]].
