## Установка на компьютере

Создайте отдельное виртуальное окружение. В Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install "https://github.com/magin67/polyform_algebra/archive/refs/tags/v0.9.0.zip"
```

В Linux/macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install "https://github.com/magin67/polyform_algebra/archive/refs/tags/v0.9.0.zip"
```

Активация окружения необязательна: используйте его интерпретатор. Сохраните последовательные фрагменты заметки в `my_example.py` и запустите `.\.venv\Scripts\python.exe my_example.py` в Windows или `.venv/bin/python my_example.py` в Linux/macOS.

## Первое вычисление

```python
import polyform_algebra
print(polyform_algebra.get_version())  # 0.9.0
```

Следующий расчёт строит единичный треугольник и проверяет остовной коэффициент и сопротивление:

```python
from math import isclose
from polyform_algebra import Point, quForm

# Construct a unit triangle and its metric polyform.
a, b, c = Point.create_list("abc")
f_ab = quForm([(a, b)])
f_ac = quForm([(a, c)])
f_bc = quForm([(b, c)])
laplacian = f_ab + f_ac + f_bc
metric = laplacian.exp()

# Check the spanning-tree coefficient and effective resistance.
tau = metric.potential(quForm.one())
r_ab = metric.norm(f_ab)
print("tau =", tau)
print("R_ab =", r_ab)
assert isclose(tau, 3.0)
assert isclose(r_ab, 2/3)
```

Ожидаются $\tau=3$ и $R_{ab}=2/3$. `exp()` вычисляет экспоненту в алгебре форм, `potential()` даёт ненормированный потенциал, `norm()` делит его на остовной коэффициент. Формат печати может различаться; `assert` проверяет численное значение.

## Проверки и исходники

В заметках приведены ожидаемые значения и проверки результатов. Полные программы и тесты доступны в [исходниках версии 0.9.0](https://github.com/magin67/polyform_algebra/tree/v0.9.0/examples/introductory). Они полезны для изучения реализации, но не требуются для запуска приведённых фрагментов или блокнота.

Для разработки можно скачать [архив исходников](https://github.com/magin67/polyform_algebra/archive/refs/tags/v0.9.0.zip), распаковать его и выполнить из папки с `pyproject.toml`:

```bash
python -m pip install -e ".[dev]"
python -m pytest tests/introductory -q
```

Здесь `python` означает интерпретатор выбранного окружения. Эти действия нужны для работы с тестами пакета.

## Если вычисление не запускается

- `ModuleNotFoundError`: убедитесь, что установка и запуск используют одно окружение.
- `NameError`: выполните предыдущие ячейки этой заметки.
- Результат отличается: проверьте `polyform_algebra.get_version()`, проводимости и порядок выполнения ячеек.
- `ValueError` при нормировке после удаления моста: это ожидаемый случай, разобранный в [[Пример - Удаление ребра и моста]].
