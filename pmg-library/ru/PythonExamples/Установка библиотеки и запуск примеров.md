## Версия кода

Для воспроизведения примеров используется ревизия [`76c433d`](https://github.com/magin67/polyform_algebra/commit/76c433de082b348caca5c0afdcb5c372361aa9f2). В ней локальные проверки выполнены на Python 3.12. Зависимости устанавливаются через pip; их версии здесь не закрепляются, поэтому фиксация кода не фиксирует окружение целиком. Новая версия библиотеки может отличаться от версии, указанной в заметке.

## Установка на компьютере

Нужны Python и Git. Команды выполняются в терминале из папки, где будет создана отдельная копия `polyform-examples`. Для Windows PowerShell:

```powershell
git clone https://github.com/magin67/polyform_algebra.git polyform-examples
cd polyform-examples
git checkout 76c433de082b348caca5c0afdcb5c372361aa9f2
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Для Linux/macOS:

```bash
git clone https://github.com/magin67/polyform_algebra.git polyform-examples
cd polyform-examples
git checkout 76c433de082b348caca5c0afdcb5c372361aa9f2
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
```

Виртуальное окружение изолирует зависимости. Активировать его необязательно: команды вызывают его Python напрямую. Установка `-e` связывает пакет с исходниками, а `[dev]` добавляет инструменты тестирования. Для обычного использования библиотеки достаточно установки без `[dev]`.

## Первое вычисление

Сохраните код в файл `my_example.py` внутри созданной папки. В Windows запустите `.\.venv\Scripts\python.exe my_example.py`; в Linux/macOS - `.venv/bin/python my_example.py`. В ноутбуке тот же код помещается в ячейку:

```python
from math import isclose
from polyform_algebra import Point, quForm

# Construct a unit triangle and its metric polyform.
a, b, c = Point.create_list(["1", "2", "3"])
f12 = quForm([(a, b)])
f13 = quForm([(a, c)])
f23 = quForm([(b, c)])
laplacian = f12 + f13 + f23
metric = laplacian.exp()

# Check the spanning-tree coefficient and effective resistance.
tau = metric.potential(quForm.one())
r12 = metric.norm(f12)
print("tau =", tau)
print("R12 =", r12)
assert isclose(tau, 3.0)
assert isclose(r12, 2/3)
```

Ожидаются `tau = 3` и `R12 ≈ 0.6666666667`; формат печати может отличаться. `Point` создаёт вершины, `quForm` задаёт квадратичную форму, сумма форм образует лапласиан. `exp()` вычисляет экспоненту в алгебре форм, `potential()` извлекает ненормированный коэффициент, `norm()` даёт нормированную метрическую оценку. Отсутствие ошибки в `assert` означает, что проверка прошла.

Для следующих экспериментов меняйте проводимости, например `laplacian = 2*f12 + f13 + f23`, затем заново вычисляйте `metric`. Ожидаемые значения также должны соответствовать новой сети. Алгебра поддерживает отрицательные коэффициенты, но при интерпретации обычной электрической сети используются допустимые проводимости. Примеры этой серии остаются в реализованной квадратичной подалгебре.

## Готовые программы и тесты

Из корня клонированного репозитория в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m examples.introductory.note06_single_edge
.\.venv\Scripts\python.exe -m examples.introductory.note07_two_edges
.\.venv\Scripts\python.exe -m pytest tests/introductory -q
```

В Linux/macOS замените путь интерпретатора на `.venv/bin/python`. Для всех тестов уберите `tests/introductory`. Программы выводят результаты, а pytest проверяет ожидаемые значения. Подробный разбор: [[Вариации связей треугольника на Python]].

## Google Colab

Откройте [Google Colab](https://colab.research.google.com/), создайте Python-ноутбук и подключите обычную среду CPU. Для этих примеров GPU не требуется. Выполняйте ячейки по порядку, например сочетанием Shift+Enter.

### Собственные вычисления

В первой ячейке установите библиотеку:

```python
%pip install "polyform_algebra @ git+https://github.com/magin67/polyform_algebra.git@76c433de082b348caca5c0afdcb5c372361aa9f2"
```

Во вторую вставьте код из раздела «Первое вычисление». Команда `%pip` устанавливает пакет в окружение текущего ядра [IPython](https://ipython.readthedocs.io/en/stable/interactive/magics.html#magic-pip). Это команда ноутбука, её не нужно переносить в обычный файл `.py`.

### Полные программы и тесты серии

Для этого варианта вместо первой установочной ячейки используйте клонирование исходников. Пакет сам по себе не включает папки `examples` и `tests`:

```python
# Run once in a fresh runtime to obtain the example and test files.
!git clone https://github.com/magin67/polyform_algebra.git /content/polyform-examples
%cd /content/polyform-examples
!git checkout 76c433de082b348caca5c0afdcb5c372361aa9f2
%pip install -e ".[dev]"
```

В следующей ячейке запустите программы и проверки:

```python
import subprocess
import sys

# Use the notebook kernel's interpreter and stop on failure.
for module in (
    "examples.introductory.note06_single_edge",
    "examples.introductory.note07_two_edges",
):
    subprocess.run([sys.executable, "-m", module], check=True)
subprocess.run(
    [sys.executable, "-m", "pytest", "tests/introductory", "-q"],
    check=True,
)
```

Повторно клонировать уже существующую папку не требуется: при повторном запуске пропустите строку `git clone`. Если библиотека уже была импортирована до смены её версии, перезапустите сеанс Python и выполните ячейки заново.

### Сохранение работы

Сохраните ноутбук в Google Drive либо скачайте файл `.ipynb`. Среда выполнения Colab временная: установленные пакеты и файлы `/content` могут исчезнуть вместе с ней. В новой среде повторите установку и запуск ячеек. Подключение Google Drive для этих примеров не требуется. Эти свойства среды описаны в [официальной справке Colab](https://research.google.com/colaboratory/faq.html).

## Проверки и типичные затруднения

- `ModuleNotFoundError: polyform_algebra`: проверьте, что установка и запуск используют одно окружение. В Colab сначала выполните установочную ячейку.
- Не найден `examples.introductory`: перейдите в корень клонированного репозитория; одной установки пакета недостаточно.
- `NameError` в ноутбуке: выполните предыдущие ячейки, создающие объекты.
- Не совпали результаты: проверьте ревизию командой `git rev-parse HEAD`, исходные проводимости и порядок выполнения ячеек.

Код первого вычисления проверен локально. Инструкции Colab подготовлены по документации сервиса; запуск в облачном сеансе Colab отдельно не проверялся. Проверка частных примеров не заменяет математического доказательства.
