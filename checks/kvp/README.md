# Проверки серии «KVP-разложение и ориентированные расширения»

Русский · [English](README.en.md)

Этот каталог содержит один воспроизводимый скрипт [verify.py](verify.py) для [девяти заметок русской версии серии](../../pmg-library/ru/%D0%98%D0%BD%D0%B2%D0%B0%D1%80%D0%B8%D0%B0%D0%BD%D1%82%D1%8B,%20%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%80%D1%8B/KVP-%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5/KVP-%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B8%20%D0%BE%D1%80%D0%B8%D0%B5%D0%BD%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5%20%D1%80%D0%B0%D1%81%D1%88%D0%B8%D1%80%D0%B5%D0%BD%D0%B8%D1%8F.md).

Требуется Python 3.9 или новее; сторонние пакеты не нужны. Все численные сравнения выполняются точно, через fractions.Fraction. Скрипт не обращается к сети и не изменяет файлы.

## Запуск

Скачайте репозиторий целиком, например архив ветки v5, или используйте существующую локальную копию. В корне репозитория выполните:

    python checks/kvp/verify.py

В Windows вместо python при необходимости используйте py -3, в Linux или macOS - python3. Путь к данным определяется по расположению скрипта, поэтому запуск по абсолютному пути работает из любого каталога.

Ожидаемый итог:

    PASS symmetric
    PASS oriented
    PASS distance
    PASS green
    PASS applications
    PASS metrics
    PASS potential
    PASS forests
    All 8 check groups passed.

Чтобы показать промежуточные точные результаты:

    python checks/kvp/verify.py --verbose

Чтобы выполнить только одну группу:

    python checks/kvp/verify.py --only green --verbose

При несовпадении выводится FAIL и место ошибки; процесс возвращает ненулевой код. Проверки используют assert, поэтому режим -O и переменная PYTHONOPTIMIZE не допускаются: скрипт выявляет отключение проверок и прекращает запуск.

## Что проверяется

| Группа | Заметки | Проверки и независимый способ вычисления |
| --- | --- | --- |
| symmetric | Определение KVP и простые графы | Девять единичных и взвешенных примеров, суммы квадратов и ортогональность; полные графы, звёзды и циклы при n от 3 до 12 |
| oriented | Ориентированные расширения | Пять примеров, численные таблицы непосредственно из Markdown; проекторы, ортогональность и треугольный базис на всех координатных таблицах при n от 3 до 6; знак циркуляционной формы |
| distance | Дистанционный оператор | Все координатные матрицы при n от 3 до 6: двойное центрирование, действие на секторы, смешивание U и V, оба правила обращения |
| green | Матрица Грина и резистенсы | Пять примеров и 40 дополнительных симметричных и сбалансированных графов при n от 3 до 7; компоненты и восстановление Грина; независимое решение заземлённых систем для столбцов r. В новом регулярном примере R дополнительно проверяется по обычным единичным токам между каждой парой |
| applications | Приложения | Четыре электрические сети, включая восьмивершинные сети с контактами; отклики из решений систем Кирхгофа; таблица взаимодействий; ранги четырёхточечных измерений при n от 4 до 8 |
| metrics | Метрические показатели | Четыре единичных и два взвешенных примера; радиус и центр из системы по R; остовы прямым перебором; производные интерполяцией остовного полинома, независимо от формулы следа. Дополнительно 15 симметричных графов при n от 3 до 7 и 12 балграфов при n от 3 до 6 |
| potential | Потенциал второго порядка | Все коэффициенты квадратичных форм при n от 3 до 7, тетраэдральное тождество и сумма четырёхточечных откликов; примеры, 15 дополнительных симметричных графов и 15 балграфов; определители Грама и независимые главные миноры |
| forests | Лесные топономы | Перебор лесов и суммы главных миноров, чистые и смешанные коэффициенты, графы с остовными коэффициентами 398 и 394, восемь знаковых таблиц при n от 3 до 6; воспроизведение опубликованных свидетельств ранга в грейдах 2-4 |

Дополнительные графы задаются в коде с фиксированными начальными состояниями генератора: 25102026, 251020262 для потенциалов и 251020269 для лесных проверок. Симметричные графы строятся с положительным связным носителем, балграфы - сложением направленных циклов. Для знаковых лесных примеров положительность и связность не требуются.

## Данные и границы проверки

Скрипт читает две части публичной серии:

- численные таблицы [ориентированных примеров](../../pmg-library/ru/%D0%98%D0%BD%D0%B2%D0%B0%D1%80%D0%B8%D0%B0%D0%BD%D1%82%D1%8B,%20%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%80%D1%8B/KVP-%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5/%D0%9E%D1%80%D0%B8%D0%B5%D0%BD%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5%20%D1%80%D0%B0%D1%81%D1%88%D0%B8%D1%80%D0%B5%D0%BD%D0%B8%D1%8F%20KVP%20-%20%D1%86%D0%B8%D1%80%D0%BA%D1%83%D0%BB%D1%8F%D1%86%D0%B8%D1%8F%20%D0%B8%20%D0%B4%D0%B8%D1%81%D0%B1%D0%B0%D0%BB%D0%B0%D0%BD%D1%81.md);
- [целочисленные свидетельства рангов P-топономов](../../pmg-library/ru/%D0%98%D0%BD%D0%B2%D0%B0%D1%80%D0%B8%D0%B0%D0%BD%D1%82%D1%8B,%20%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%80%D1%8B/KVP-%D1%80%D0%B0%D0%B7%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5/%D0%9F%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%D1%80%D0%B0%D0%BD%D0%B3%D0%BE%D0%B2%20P-%D1%82%D0%BE%D0%BF%D0%BE%D0%BD%D0%BE%D0%BC%D0%BE%D0%B2.json).

Остальные исходные графы и ожидаемые значения заданы непосредственно в скрипте. Для опубликованных свидетельств заново перечисляются леса, сравниваются все коэффициентные векторы и вычисляются ранги. Балансное тождество не используется для получения этих векторов.

Успешный запуск подтверждает описанные конечные вычисления. Общие утверждения обоснованы в заметках; скрипт не является доказательством гипотезы о рангах при произвольном грейде. Здесь также нет проверки эффективности электрометрии на экспериментальных данных и реализации неполного или взвешенного статистического оценивания.
