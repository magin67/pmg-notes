# Проверки диагонального представления полиформ

Точная проверка примера пути P3 из первой спектральной заметки:

    python checks/spectral/verify_diagonal.py

Требуется Python 3.10 или новее. Внешние пакеты не нужны. Скрипт использует общие операции из `checks/dual/verify_vector.py` и `checks/dual/exterior_checks.py`, выводит JSON и не записывает файлы. Не запускать с `-O`: проверки используют `assert`.

Ненормированные целочисленные собственные векторы позволяют проверять нормированные тензоры без приближений: их квадратичные формы делятся на координатные нормы 2 и 6. Независимо сопоставляются:

- лапласиан из рёбер, спектральное разложение и псевдообратная матрица;
- все грейды реберной и спектральной внешних экспонент;
- оба направления внешнего удаления в согласованных прямом и двойственном базисах;
- центрированный перенос дуальной экспоненты, нормировки T3 и предельных грейдов;
- координатные, резистивные и энергетические оценки;
- главные миноры и прямой перебор обычных и корневых лесов;
- попарные резистенсы и индекс Кирхгофа.

Это точная проверка конкретного примера, а не вычислительное доказательство общих утверждений.

Для воспроизведения трёх SVG-рисунков дополнительно требуется Matplotlib:

    python checks/spectral/draw_diagonal.py

Перед построением выполняются точные проверки. SVG сохраняются рядом с заметкой в `pmg-library/ru/Спектры и диагонализация в алгебре полиформ`; необязательный параметр `--preview-dir PATH` сохраняет PNG для визуальной проверки. При построении кривых и размещении рисунков используются приближённые координаты, а математические параметры и подписи проверены точно.
