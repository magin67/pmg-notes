# Проверки спектральной серии

[English](README.en.md)

Все семь программ draw_*.py поддерживают параметр --lang en для английских рисунков. По умолчанию сохраняется русский вариант (--lang ru). Численные данные и проверки общие; переводы подписей и описаний находятся в figure_labels_en.json. Параметр --preview-dir PATH работает для обоих языков.

Точная проверка примера пути P3 из первой спектральной заметки:

    python checks/spectral/verify_diagonal.py

Требуется Python 3.10 или новее. Внешние пакеты не нужны. Скрипт использует общие операции из `checks/dual/verify_vector.py` и `checks/dual/exterior_checks.py`, выводит JSON и не записывает файлы. Не запускать с `-O`: проверки используют `assert`.

Ненормированные целочисленные собственные векторы позволяют проверять нормированные тензоры без приближений: их квадратичные формы делятся на координатные нормы 2 и 6. Независимо сопоставляются:

- лапласиан из рёбер, спектральное разложение и псевдообратная матрица;
- все грейды реберной и спектральной внешних экспонент;
- оба направления внешнего удаления в согласованных прямом и двойственном базисах;
- центрированный перенос дуальной экспоненты, нормировки T3 и предельных грейдов;
- координатные, резистивные и энергетические оценки;
- главные миноры и прямой перебор обычных и корневых лесов;
- попарные резистенсы и индекс Кирхгофа.

Это точная проверка конкретного примера, а не вычислительное доказательство общих утверждений.

Для воспроизведения трёх SVG-рисунков дополнительно требуется Matplotlib:

    python checks/spectral/draw_diagonal.py

Перед построением выполняются точные проверки. SVG сохраняются рядом с заметкой в `pmg-library/ru/Спектры и диагонализация в алгебре полиформ`; необязательный параметр `--preview-dir PATH` сохраняет PNG для визуальной проверки. При построении кривых и размещении рисунков используются приближённые координаты, а математические параметры и подписи проверены точно.

## Собственные подпространства и проекторы на C4

    python checks/spectral/verify_projectors.py
    python checks/spectral/draw_projectors.py

Проверка использует только стандартную библиотеку и общие операции из соседнего `verify_diagonal.py` и папки `checks/dual`. Для рисунков нужен Matplotlib; параметр `--preview-dir PATH` действует так же, как у первого скрипта построения.

Точно сопоставляются два ортонормированных базиса собственного подпространства с числом 2, полиномиальные формулы проекторов, все шесть форм выбора направлений и соответствующие операторы на внешних степенях. Грейды экспоненты сравниваются с независимым разложением по рёбрам цикла. Дополнительно проверяются дуальные удаления для каждого грейда и каждого набора чисел направлений, центрированное отождествление, нормировки T4, корневые и обычные лесные коэффициенты, обе метрические оценки, резистенсы и изменение вкладов отдельных мод при повороте базиса.

## Изоспектральная взвешенная пара на четырёх вершинах

    python checks/spectral/verify_cospectral.py
    python checks/spectral/draw_cospectral.py

Проверка использует только стандартную библиотеку и общие операции соседних проверок. Для двух SVG нужен Matplotlib; параметр --preview-dir PATH сохраняет PNG для визуального контроля. Рисунки строятся после успешной точной проверки.

Лапласианы строятся по рёбрам независимо от проекторов и общего собственного базиса. Проверяются спектр 0,4,4,8, различие проекторов, матрицы Грина, все грейды прямых и перенесённых дуальных экспонент, характеристические полиномы, старшие нормировки и все попарные резистенсы с вкладами подпространств. Обычные и корневые коэффициенты независимо получаются перебором лесов. Для обоих графов при множителях проводимостей 1/2, 1, 2 и 3 проверены оба дуальных удаления во всех грейдах; дуальный первый грейд сверяется с независимо обращённой редуцированной матрицей. Отдельно проверено, что одинаковое масштабирование прямых и дуальных коэффициентов нарушает взаимность.

## Моды путей и циклов: P6, C6 и C5

    python checks/spectral/verify_path_cycle.py
    python checks/spectral/draw_path_cycle.py

Требуются SymPy и NumPy, а для четырёх рисунков дополнительно Matplotlib. Параметр `--preview-dir PATH` сохраняет PNG для визуальной проверки. Перед построением выполняются все проверки третьей заметки.

Для трёх основных примеров проекторы точно вычисляются полиномиальной интерполяцией от лапласиана, построенного по рёбрам. Проверяются их ортогональность, ранги, полнота, спектральное восстановление лапласиана и гриниана. Тригонометрические компоненты вычисляются численно и сопоставляются с точными проекторами с погрешностью менее 10⁻¹².

Корневые полиномы независимо получаются из определителя, спектрального произведения и прямого перебора лесов. Также проверяются обычные лесные коэффициенты, обращение коэффициентов для гриниана, число остовных деревьев и нормировки старших грейдов. Для C6 проверена формула второго грейда как равенство полиформ, включая нильпотентность форм парных подпространств. Все попарные сопротивления и указанные в тексте вклады подпространств сравниваются точно; индексы Кирхгофа проверяются суммированием и через след гриниана.

Дополнительная численная проверка охватывает 45 графов: пути P2–P24 и циклы C3–C24. Сравниваются ортонормированность, собственные уравнения, спектральная формула гриниана с независимым обращением матрицы и электрические формулы сопротивлений. Допуск абсолютной погрешности равен 10⁻¹¹. Это проверка конечного набора примеров; общие утверждения доказаны в тексте заметки.

## Чебышёвские преобразования пути

    python checks/spectral/verify_chebyshev.py
    python checks/spectral/draw_chebyshev.py

Для проверок требуется SymPy, для двух рисунков дополнительно Matplotlib. Параметр `--preview-dir PATH` сохраняет PNG для визуальной проверки. Скрипт построения сначала выполняет точные проверки.

Для P2–P18 сопоставляются 374 матрицы: шаги от 0 до 2n+1 вычисляются полиномиальной рекурсией и независимо через свёртку шагового графа на 2n вершинах. Проверяются знаки, проводимости, компоненты, классификация через НОД, нулевые моды, отражение и периодичность. На P6 отдельно проверяются 49 пар композиции преобразований.

Для перехода P6 в C6 точно проверены перенумерация, объединение проекторов исходного пути, гриниан и вклад каждой моды в R16. Внешняя экспонента сопоставляется в трёх представлениях: по рёбрам, через первый грейд и по формам собственных подпространств. Проверяются все грейды M и N, обращение скалярных коэффициентов, обе операции дуального удаления и старшие нормировки 6T6 и T6/216. Для несвязного шага m=3 проверены спектр, ранг 4 и обнуление пятого грейда.

## Спектральный конус фиксированного базиса P3

    python checks/spectral/verify_cone.py
    python checks/spectral/draw_cone.py

Проверка использует стандартную библиотеку и общие операции предыдущих проверок. Для двух рисунков нужен Matplotlib; параметр `--preview-dir PATH` сохраняет PNG. Все математические проверки выполняются до построения рисунков.

Равенство спектральной и реберной матриц проверяется по двум матрицам коэффициентов, а знаковые условия — на 697 рациональных точках. Проверены 432 случая обращения положительных координат и 83 неотрицательные матрицы в фиксированном базисе для обратного перехода из Perron spectracone. Перебор всех восьми простых размеченных графов на трёх вершинах выделяет ровно четыре диагональных в выбранном базисе.

На восьми точках конуса, включая нулевую и несвязную, точно сопоставлены внешние экспоненты по модам и рёбрам, обычные и корневые лесные коэффициенты и старшие грейды. На шести связных примерах дополнительно проверены матричное обращение, прямые и дуальные удаления, центрированное отождествление, обе метрические оценки, резистенсы и индекс Кирхгофа. Отдельно проверены матрица Грина для точки (4,1), пример коммутирования при кратном спектре и шесть шагов чебышёвской орбиты P3. Конечные проверки контролируют примеры и рисунки; общие утверждения доказаны в тексте.

## Проекция на фиксированный базис и потеря информации

    python checks/spectral/verify_projection.py
    python checks/spectral/draw_projection.py

Проверка использует стандартную библиотеку и существующие операции алгебры полиформ. Для двух SVG нужен Matplotlib; параметр --preview-dir PATH сохраняет PNG. Математические проверки выполняются перед построением.

Для базиса C4 с повёрнутыми модами точно проверены спектральная и реберная записи, диагональная и блочная проекции, отрицательные реберные коэффициенты свободной проекции, координаты ближайшего графа в конусе и разложение квадрата ошибки. Оптимальность ближайшей точки подтверждается её совпадением с проекцией на нарушенное полупространство и выполнением остальных ограничений.

Проверена 21 рациональная точка семейства с общей диагональю (10,4,4). Для пяти допустимых графов и свободной проекции сопоставлены все грейды через внешние степени, матричные миноры и независимое раскрытие по рёбрам. Проверены обычные и корневые лесные коэффициенты, оба дуальных удаления, центрированное отождествление, старшие нормировки, метрические оценки, гриниан, резистенсы и индекс Кирхгофа. Проекция каждого готового грейда сравнивается с грейдом экспоненты проекции.

Перебор всех 64 простых размеченных графов на четырёх вершинах проверяет сохранение следа, идемпотентность, ортогональное разложение ошибки, неравенства для корневых коэффициентов и точное выражение ошибки через второй коэффициент. На 38 связных графах дополнительно проверены положительность диагональных оценок и неравенство для диагонали обратной матрицы. Пример ребра на трёх вершинах проверяет возможное увеличение ранга после проекции. Конечные проверки служат контролем примеров; общие утверждения обоснованы в заметке.
