# Проверки серии «Цепи из ядер»

Комплект сопровождает пять русских заметок серии, от «Ядра, швы и допустимые цепочки» до «Замыкание цепи: кольцо и эффект Мёбиуса». Требуется Python 3.10 или новее; используются только стандартная библиотека и проверочные функции серии «Граничные полиномы и сочленение графов» из `checks/boundary`. Запускать из корня репозитория без `-O`, отключающего утверждения `assert`.

Итоги общей проверки, внесённые исправления и границы вычислительного покрытия зафиксированы в [REVIEW_RU.md](REVIEW_RU.md). Маршрут чтения и происхождение результатов собраны в [навигаторе серии](../../pmg-library/ru/Цепи%20из%20ядер/Цепи%20из%20ядер.md).

## Точные проверки

```bash
python checks/core-chains/verify_admissible_chains.py
```

Проверяются 16 конфигураций цепочек и 26 шагов сборки:

- одиночный цикл, одноточечный шов, одно общее ребро, шов из двух рёбер;
- разные размеры ядер и смена размера активной границы;
- оба направления соответствия вершин швов;
- точные пересечения образов ядер, отсутствие несоседних контактов, связность, числа вершин и рёбер, цикловой ранг;
- полные полиномы **каждого** выходного лесного состояния: перенос по паспортам сопоставляется с независимым перебором рёбер объединённого графа;
- последний шаг без выхода, снятие отметки с компоненты, ставшей внутренней, и сохранение изолированных входных вершин отдельного фрагмента;
- отклонение трёх недопустимых конструкций с рисунка.

Для двух трёхгексагональных цепочек вычисляются определители исходных лапласианов и радиус в точной рациональной арифметике. Используются две формулы: энергия диагонали обратного заземлённого лапласиана и центрированная матрица Грина

$$
\mathbf{Gr}=(\mathbf L+\mathbf1\mathbf1^{\mathsf T}/n)^{-1}-\mathbf1\mathbf1^{\mathsf T}/n,\qquad
\rho=\frac{\operatorname{tr}\mathbf{Gr}}n+\frac14\mathbf d^{\mathsf T}\mathbf L\mathbf d,
\quad d_i=\mathrm{Gr}_{ii}
$$

Вторая формула следует из условий равноудалённости центра от центрированных вершин: его квадрат удаления от центроида равен второй части, а средняя норма вершин - первой. В обоих случаях `tau = 204`, `rho = 43595/41616`. Подграфы вершин степени 3 имеют соответственно два и три ребра; это отдельное свидетельство неизоморфности.

Файл `admissible-chains-results.json` создаётся заново при запуске. Для каждой проверенной цепочки в нём записаны циклический порядок вершин каждого ядра, упорядоченные отождествлённые вершины каждого шва и итоговые множества вершин и рёбер. Общие числовые имена задают соответствия вершин; рёбра шва входят в результат один раз.

Эта программа проверяет реализацию примеров и переноса, но не заменяет доказательства заметки.

## Матроидная инвариантность и два шестиугольных графа

```bash
python checks/core-chains/verify_matroid_invariance.py
```

Проверяются 11 конфигураций и все 278 536 наборов их рёбер. Для каждой конфигурации явно сохраняются ядра, соответствия вершин швов, итоговый граф и отдельное двойственное ребро для каждого исходного ребра. Внешняя грань имеет номер 0. Кратности пучков сверяются с размерами ядер и швов.

Для каждого набора $A\subseteq E$ вычисляются ранги непосредственно по компонентам связности исходного графа и двойственного мультиграфа, после чего проверяется

$$
r_G(A)=|A|+r_H(E\setminus A)-N
$$

У пар с одинаковыми упорядоченными размерами сопоставляются полные массивы рангов при явной биекции рёбер внутри двойственных пучков. Для двух шестиугольных цепочек эта биекция записана отдельно. В отчёт включены контрольные суммы массивов; при запуске сравниваются сами массивы, а не только контрольные суммы или числа деревьев.

Обычные и корневые лесные коэффициенты подсчитываются перебором наборов рёбер с сохранением всех изолированных вершин. Множитель корневого леса равен произведению размеров его компонент. Корневые коэффициенты независимо сверяются с коэффициентами $\det(I+t\mathbf L)$, вычисленными через следы степеней лапласиана и тождества Ньютона.

Радиус вычисляется без предположения об инвариантности:

1. По обратному заземлённому лапласиану при опоре 0 и энергетической формуле.
2. Через отдельное обращение $\mathbf L+\mathbf1\mathbf1^{\mathsf T}/n$, построение матрицы резистенсов $\mathbf R$ и решение условий равноудалённости центра: $\mathbf R\alpha=c\mathbf1$, $\mathbf1^{\mathsf T}\alpha=1$, $\rho=c/2$.
3. Через независимо перебранные двухкомпонентные леса, частоты рёбер в деревьях и лесное тождество для радиуса. Эффективные резистенсы рёбер дополнительно сверяются с этими частотами.

Энергия проверяется для каждой опорной вершины. Детерминант исходного лапласиана сверяется с перебором деревьев и определителем редуцированного двойственного лапласиана. Во всех операциях используется точная рациональная арифметика.

Для обоих шестиугольных графов: `tau = 204`, `rho = 43595/41616`, `f12 = 1181`, `H2 = 36713/3468`. Однако `p4 = 21509` и `p4 = 21508`; различаются и характеристические полиномы. Неизоморфность проверяется отдельно по индуцированным подграфам вершин степени 3: два раздельных ребра и трёхрёберный путь.

Дополнительные конфигурации охватывают одиночный цикл, точечные и многорёберные швы, различные направления соответствия, разные размеры ядер и случай полного покрытия вершин внутреннего ядра двумя непересекающимися швами. Файл `matroid-invariance-results.json` создаётся заново при запуске и содержит все графы, коэффициенты, соответствия рёбер и точные метрические данные. Эти конечные проверки поддерживают примеры; общая теорема доказывается в заметке. Эта программа не проверяет общую остовную рекурсию; отдельные проверки рекурсии описаны ниже. Замыкания и спектральный автомат в этот комплект не входят.

## Остовные полиномы и рекурсия

```bash
python checks/core-chains/verify_spanning_polynomials.py
```

Проверяются 76 явно собранных конфигураций и 286 подцепочек. Для каждой подцепочки определитель минора её исходного лапласиана сравнивается с рекурсией, трёхдиагональным определителем и суммой по паросочетаниям. Двойственный лапласиан независимо строится по принадлежности рёбер циклам. Контролируются допустимость пересечений, связность, число вершин и рёбер; включены оба направления отождествления, разные размеры ядер, одноточечные швы и полное покрытие вершин внутреннего ядра двумя швами. Для четырёх восьмиугольников проверены все перестановки размеров швов `(1, 2, 3)` и `(2, 3, 4)`.

Для формальных параметров разложение определителя по всем перестановкам сравнивается с разложением по паросочетаниям при `1 <= N <= 7`. Рекурсия нормированных полиномов, биномиальные коэффициенты и преобразованные полиномы Чебышёва второго рода сравниваются как полиномы при `0 <= N <= 20`. Дополнительно проверяются значения при `x = 0` и `x = 1/2`, тождество соединения двух однородных континуантов и характеристические определители матрицы смежности вспомогательного пути на шести рациональных значениях аргумента для `1 <= N <= 8`.

`spanning-polynomials-results.json` сохраняет циклические порядки ядер, упорядоченные швы, соответствия локальных индексов и общих имён, итоговые вершины и рёбра, а также числа деревьев всех начальных подцепочек. В каждой тройке `vertex_identifications` записаны индекс вершины в предыдущем ядре, индекс в новом ядре и общее имя вершины. Все индексы начинаются с нуля. Числа считаются в точной целой или рациональной арифметике. Радиусы здесь не вычисляются и по остовному числу не выводятся.

Внутренний исходник приводил примеры общей остовной рекурсии, но прилагавшаяся к нему программа `check-examples.py` проверяла другие конструкции и не воспроизводила эту таблицу. Публичная программа воспроизводит таблицу и необходимые алгебраические проверки непосредственно. Конечный набор проверок не заменяет доказательств в заметке.

## Границы инвариантности

```bash
python checks/core-chains/verify_invariance_limits.py
```

Проверяются 20 явно собранных графов: путь и звезда из четырёх шестиугольников; три размещения и направления швов одного фиксированного дерева циклов; две сборки с несвязными швами; два случая тетраэдров; три случая кубов; четыре боковых сочленения шестигранных призм и две соответствующие цепочки оснований; два малых графа с одинаковым остовным числом и разными радиусами.

Для каждого графа сохраняются локальные шаблоны всех ядер, отображения локальных вершин в итоговые, упорядоченные списки соответствий шва, все фактические пересечения пар ядер и итоговые рёбра. Общие рёбра отождествляются и остаются единичными. Проверяются инъективность образа каждого ядра, связность и точность пересечений. Единственный намеренный дополнительный контакт — общая вершина двух внешних тетраэдров при смежных швах среднего. Он явно разрешён в данных этого примера и запрещён в остальных сборках.

Остовное число вычисляется как определитель исходного заземлённого лапласиана. Радиус независимо находится по энергии диагонали его обратной матрицы и через отдельное обращение центрированного лапласиана с решением уравнений равноудалённости центра. Все вычисления рациональные; энергия дополнительно проверяется для каждой опорной вершины. Программа использует `direct_metrics` из `verify_matroid_invariance.py`, не подставляя предполагаемую инвариантность.

Для деревьев циклов двойственный мультиграф строится по принадлежности каждого ребра ядрам. Его кофактор сравнивается с матрицей теоремы; на одно- и двухэлементных наборах, их дополнениях и воспроизводимой выборке проверяется ранговое тождество двойственности. Это конечная проверка реализации, а не замена общего доказательства.

Для куба перебираются все перестановки вершин и находятся орбиты пар непересекающихся рёбер при фиксированном первом ребре. Для призмы проверяются числа четырёхциклов через рёбра обоих типов. При согласованных слоях строится явный изоморфизм с декартовым произведением цепочки основания на K2 и проверяется формула через сдвинутый лапласиан основания. Для пары графов с `tau = 12` перебираются все 128 наборов рёбер каждого графа; обычных двухкомпонентных лесов получается 30 и 32, а радиусы дополнительно проверяются по лесному тождеству.

`invariance-limits-results.json` содержит все конструкции, точные дроби радиусов, степени, резистенсы до опоры и координаты центров. В `attachments` поля `parent_local` и `child_local` сопоставляются по позициям; `common_vertices_in_order` содержит итоговые имена. Локальные номера ядер и вершин начинаются с нуля; в рисунках ядра обозначаются K1, K2 и т. д. Замыкания здесь не рассматриваются.

## Обычные и скрученные замыкания

```bash
python checks/core-chains/verify_closures.py
```

Проверяются 37 замкнутых графов: 24 полосы для N = 3, 4, 5, 6, ядер C4, C6, C8 и двух соответствий крайних рёбер; кольцо шести шестиугольников вокруг пустой ячейки; 12 замыканий призм для (N, m) = (3, 3), (4, 4), (3, 5) со всеми сдвигами основания.

Каждая конструкция начинается с открытого графа. В `closure-results.json` сохраняются его рёбра и локальные вершины ядер, последнее соответствие, полный `quotient_map`, исключаемые повторные рёбра, фактические пересечения ядер и итоговые рёбра. Проверяются отсутствие петель, инъективность образов ядер, связность, размеры и точность всех контактов. Лапласиан по итоговым рёбрам сравнивается с переносом открытого лапласиана по классам отождествления после удаления одной копии конечного шва. Без удаления получается ровно дополнительный лапласиан общего ребра или основания; эта ошибка учёта также проверяется явно.

Для каждого графа остовное число считается по минору исходного лапласиана. Радиус находится двумя независимыми рациональными расчётами `direct_metrics`, энергия проверяется при каждой опорной вершине. Для квадратных полос обе величины сверяются с чебышёвскими формулами; проверяются автоморфизмы сдвига и обмена рядов и равномерные координаты центра.

Для удлинённых полос дополнение Шура сравнивается с сетью продольных проводимостей 1/ell, а внутренний определитель равен ell^(2N). Определитель сокращённой сети с этим множителем сверяется с полным определителем. Симметричные и антисимметричные блоки проверяются непосредственно; определитель и след обратного антисимметричного блока сравниваются с формулами Чебышёва. Радиусы при ell > 1 вычисляются по всем вершинам, без переноса формулы квадратной модели.

Граничное правило стягивания для N = 3 и 4 проверяется перебором соответственно 512 и 4096 наборов рёбер при каждом из двух замыканий. Полином, полученный фильтрацией состояний четырёхточечной границы, совпадает с обычным лесным полиномом фактического замкнутого графа. Для кольца построен независимый граф на шестиугольной решётке и явный изоморфизм с моделью продольных путей длины 1 и 3.

Для призм чебышёвское произведение вычисляется точно с помощью матрицы циклического сдвига поперечного слоя. Если S - такая матрица, Z = 2I - (S + S^T)/2, то матрица M = 2T_N(Z) - S^r - S^(-r) имеет нулевые суммы строк. Число деревьев равно N, умноженному на её главный минор порядка m - 1. Это точная проверка произведения, без округления косинусов. Сдвиги r и m - r дополнительно сопоставляются явным изоморфизмом j → -j.

Ядра и вершины в этих данных нумеруются с нуля; в рисунках к замыканиям используются K₀, K₁ и т. д. Проверки конечны и не заменяют общих доказательств.
