# Проверки серии «Цепи из ядер»

Комплект сопровождает русскую заметку «Ядра, швы и допустимые цепочки». Требуется Python 3.10 или новее; используются только стандартная библиотека и проверочные функции опубликованной серии С08 из `checks/boundary`. Запускать из корня репозитория без `-O`, отключающего утверждения `assert`.

## Точные проверки

```bash
python checks/core-chains/verify_admissible_chains.py
```

Проверяются 16 конфигураций цепочек и 26 шагов сборки:

- одиночный цикл, одноточечный шов, одно общее ребро, шов из двух рёбер;
- разные размеры ядер и смена размера активной границы;
- оба направления соответствия вершин швов;
- точные пересечения образов ядер, отсутствие несоседних контактов, связность, числа вершин и рёбер, цикловой ранг;
- полные полиномы **каждого** выходного лесного состояния: перенос по паспортам сопоставляется с независимым перебором рёбер объединённого графа;
- последний шаг без выхода, снятие отметки с компоненты, ставшей внутренней, и сохранение изолированных входных вершин отдельного фрагмента;
- отклонение трёх недопустимых конструкций с рисунка.

Для двух трёхгексагональных цепочек вычисляются определители исходных лапласианов и радиус в точной рациональной арифметике. Используются две формулы: энергия диагонали обратного заземлённого лапласиана и центрированная матрица Грина

$$
\mathbf{Gr}=(\mathbf L+\mathbf1\mathbf1^{\mathsf T}/n)^{-1}-\mathbf1\mathbf1^{\mathsf T}/n,\qquad
\rho=\frac{\operatorname{tr}\mathbf{Gr}}n+\frac14\mathbf d^{\mathsf T}\mathbf L\mathbf d,
\quad d_i=\mathrm{Gr}_{ii}
$$

Вторая формула следует из условий равноудалённости центра от центрированных вершин: его квадрат удаления от центроида равен второй части, а средняя норма вершин - первой. В обоих случаях `tau = 204`, `rho = 43595/41616`. Подграфы вершин степени 3 имеют соответственно два и три ребра; это отдельное свидетельство неизоморфности.

Файл `admissible-chains-results.json` создаётся заново при запуске. Для каждой проверенной цепочки в нём записаны циклический порядок вершин каждого ядра, упорядоченные отождествлённые вершины каждого шва и итоговые множества вершин и рёбер. Общие числовые имена задают соответствия вершин; рёбра шва входят в результат один раз.

Вычисления проверяют реализацию примеров и переноса, но не заменяют доказательства заметки. Общая матроидная инвариантность, остовная рекурсия, замыкания и спектральный автомат не входят в этот проверочный комплект.

## Рисунки

```bash
python checks/core-chains/draw_admissible_chains.py
```

Создаются три SVG в `pmg-library/ru/Цепи из ядер`:

1. `Две сборки трёх шестиугольников.svg`: две точные сборки и вспомогательная схема ядер.
2. `Присоединение ядра и перенос активной границы.svg`: принадлежность общего ребра, смена отметок и вставка для трёхвершинного шва.
3. `Допустимая цепочка и нарушения условий.svg`: допустимая модель и три отдельно проверяемых нарушения.

Цвета дополнены буквами, номерами и подписями. SVG содержит редактируемый текст, заголовок и описание; графовые вершины показаны кругами. Стрелки вдоль швов задают порядок соответствия, а не ориентацию рёбер. На панели дополнительного контакта пунктир задаёт отождествление вершин 7 и 12, а не новое ребро. Все укладки являются схемами абстрактных графов.
