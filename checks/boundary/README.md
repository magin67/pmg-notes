# Проверки граничных лесных паспортов и резистивной геометрии

Скрипты сопровождают шесть русских заметок серии «Граничные полиномы и сочленение графов». Для запуска достаточно стандартной библиотеки Python 3.10 или новее. Запускать из корня репозитория без флага `-O`, отключающего проверочные утверждения `assert`.

## Точные проверки

```bash
python checks/boundary/verify_forest_states.py
```

Проверка перебирает подмножества различимых рёбер. Циклы выявляются объединением компонент; все вершины сохраняются, включая изолированные. Из каждого принятого леса независимо извлекаются разбиение границы, внутренние компоненты и признак рощи.

Проверяются:

- все 16 лесов единичного пути P5 с границей `{a,c,e}`, каждый коэффициент пяти полиномов состояний, сумма `(1+t)^4` и девять рощ;
- тот же путь с весами `2,3,5,7`;
- добавление изолированной внутренней вершины: полиномы не меняются, число внутренних компонент увеличивается на один;
- два сочленения с одним партнёром на границе `{x,y,z}`, содержащим единственное ребро `xy`: по 32 подмножества рёбер для каждого результата;
- различимые параллельные рёбра с рациональными весами, несвязный граф, одноточечная граница и граница из всех вершин.

Для всех этих случаев сумма полиномов состояний сопоставляется с прямой лесной суммой, а коэффициенты рощ - с непосредственным условием, что каждая компонента встречает границу. Проверки примеров не заменяют общих доказательств в заметке.

## Проверки стягивания

```bash
python checks/boundary/verify_contraction.py
```

Скрипт для «Стягивание вершин как граничный тест» использует соседний `verify_forest_states.py`. На точных рациональных числах сопоставляются:

- ранговый критерий совместимости граничных разбиений;
- непосредственная ацикличность подмножества различимых рёбер в фактор-графе;
- ранг матрицы инцидентности после добавления вспомогательных деревьев внутри стягиваемых блоков;
- полином отклика по исходным лесам и прямой лесной полином фактор-графа;
- редуцированный определитель Кирхгофа, перечисление остовных деревьев и, для связного исходного графа, резистивный определитель.

Проверяются все 64 подграфа взвешенного K4, все их непустые границы и все разбиения каждой границы. Дополнительно разобраны три стягивания P5, треугольник с весами 2,3,5, рациональные параллельные рёбра и петля, несвязный граф, избыточные пары, одноточечный граф и масштабирование базиса. Объединение параллельных рёбер по сумме проводимостей сравнивается с подсчётом по исходным меткам.

Всего проверяются 3284 конфигурации стягивания, в том числе 1956 случаев с формулой резистивного грамиана. Проверки дополняют доказательства, приведённые в заметке.

## Проверки спаривания

```bash
python checks/boundary/verify_pairing.py
```

Проверщик заметки «Сочленение компонент как спаривание граничных данных» использует соседние `verify_forest_states.py` и `verify_contraction.py`. В нём сравниваются:

- полином и все состояния результата, вычисленные по паспортам, с прямым перебором лесов объединённого графа;
- пары конкретных лесов с допустимыми наборами различимых рёбер результата;
- отклики как произведение матрицы на паспорт с прямым перебором в стянутых графах;
- формулы через прямую и обратную матрицы для границ из двух и трёх вершин;
- совместимость представителей разбиений с рангом их общей матрицы инцидентности для границ размера 1-4.

Основное семейство содержит все пары из 16 подграфов взвешенного графа на четырёх вершинах с рёбрами `03,13,23,01` весов `2,3,5,7`. Для каждой пары проверяются границы `{0}`, `{0,1}`, `{0,1,2}`. Дополнительно проверяются два пути, обе разметки P5 с партнёром, перестановки трёхточечной границы, дробные параллельные веса, петля, изолированная внутренняя вершина, варианты общего ребра и четырёхточечное спаривание без обращения матрицы. Последовательное сочленение трёх частей сопоставляется с прямым перебором.

Всего проверяются 781 конфигурация пары графов и 255 пар представителей состояний. Матрицы также проверяются при всех перестановках границы размера 1-4. Используется точная рациональная арифметика; это конечные проверки, а не замена общих доказательств.

## Остовной слой и резистивная геометрия

```bash
python checks/boundary/verify_spanning_geometry.py
```

Проверщик использует соседние `verify_forest_states.py`, `verify_contraction.py` и `verify_pairing.py`. На точных рациональных числах сопоставляются:

- выделение рощ по старшей степени каждого состояния и непосредственное отсутствие внутренних компонент;
- вес полностью разделённых рощ и определитель внутреннего блока лапласиана;
- остовной коэффициент по Кирхгофу и произведение внутреннего определителя на граничный кофактор;
- резистивный грамиан исходного графа, обратная редуцированная матрица отклика и метрика эффективного графа;
- остовное спаривание рощ, определитель суммы грамианов и прямой подсчёт деревьев сочленения;
- сложение откликов, метрика результата и поправка при общем изменении базиса.

Основное семейство содержит все 38 связных подграфов взвешенного K4 (веса `1,2,3,5,7,11`) и все 15 непустых границ каждого: 570 конфигураций. Дополнительно проверяются 266 пар графов, в том числе выбранные восемь разреженных и плотных представителей при границах размера 1-4, два P5, все шесть перестановок трёхточечной границы и рациональные параллельные рёбра с петлёй. Проверяется также одноточечный граф и соглашение о пустых определителях.

Численные примеры воспроизведены отдельно: исключение внутренних вершин P5, сочленение двух путей с остовным коэффициентом 16, четырёхлучевая звезда и её эффективный K4, две сети с одинаковыми откликами и весами рощ, но разными лесными паспортами. Для последних проверены также полиномы после добавления одного и того же граничного ребра.

Это вычислительный контроль доказательств заметки, а не замена общих выводов или теоремы Kenyon–Wilson.

## Сокращение числа состояний

```bash
python checks/boundary/verify_reduction.py
```

Проверщик использует `verify_forest_states.py`, `verify_contraction.py` и `verify_pairing.py`. Для границ размера 1-5 точно вычисляются ранги полной лесной матрицы, её главной подматрицы на непересекающихся разбиениях и остовной матрицы. Все значения совместимости независимо проверяются рангом матрицы инцидентности объединённых представителей. Проверяются нулевые блоки, невырожденность блоков между дополнительными рангами и равенство определителей двух подматриц.

Получены ранги `1,2,5,14,42` при числе состояний `1,2,5,15,52`. Для четырёх точек проверены вектор радикала, `det(A)=8`, определитель сокращённой матрицы `-64`, факторизация полной матрицы через сокращение и ненулевой ответ структурного отношения на полностью разделённый тест.

Проверены 67 полных паспортов: все 64 подграфа взвешенного K4, единичное пересекающееся паросочетание, звезда с внутренним центром и пример с рациональными весами, параллельными рёбрами, петлёй и изолированной внутренней вершиной. Отклики на все 15 стягиваний получены прямым перебором лесов фактор-графов и сопоставлены с матричными формулами.

Для 217 сочленений сравниваются полный закон, сокращённый закон, закон по 14 тестовым откликам и непосредственный перебор лесов результата. Включены все 24 перестановки четырёхточечной границы. Отдельно воспроизведены отрицательные сокращённые координаты и ошибка от простого удаления состояния `ac|bd`.

Все вычисления рациональные. Они иллюстрируют общий результат, доказанный в заметке с опорой на Mannens–Nederlof и Kenyon–Wilson, и не заменяют его.

## Спектральный граничный паспорт

```bash
python checks/boundary/verify_spectral_boundary.py
```

Скрипт использует стандартную библиотеку Python и перебор лесов из `verify_forest_states.py`. Полиномы представлены точными рациональными коэффициентами. Определители и знаковые кофакторы вычисляются непосредственно, без делений, разложением по подмножествам столбцов; числовые значения дополнительно сверяются с независимым исключением Гаусса.

Для 80 компонент проверяются тождество Якоби и характеристический полином, независимо полученный перебором корневых лесов. Набор включает все 64 подграфа K4, восемь взвешенных подграфов треугольника, примеры заметки, пустое множество внутренних вершин, изолированную внутреннюю вершину, рациональные веса, параллельные рёбра и петлю с нулевым вкладом в лапласиан.

Для 528 сочленений с раздельными рёбрами и 48 сочленений с общим взвешенным ребром сравниваются все пять координат, полученные законом сочленения и прямым вычислением миноров результата. Проверяются путь и звезда с одинаковыми обычными паспортами, зависимость от отмеченной пары, сохранение исходных степеней в главных минорах, случай нулевых внутренних определителей при `xi=2`, 24 порядка вершин, перестановка границы, ассоциативность и специализация к электрическому отклику при `xi=0`.

Скрипт иллюстрирует доказанные в заметке формулы; конечный набор не заменяет доказательств и не устанавливает научный приоритет. Предполагается обычный лапласиан по инцидентности, а не матрица смежности и не лапласиан с заземляющими добавками.

## Рисунки

```bash
python checks/boundary/draw_forest_states.py
```

Программа создаёт пять SVG рядом с русской заметкой. Она использует только стандартную библиотеку Python и соседний `verify_forest_states.py`; дополнительные пакеты не требуются. Текст в SVG остаётся редактируемым, каждый рисунок содержит заголовок и описание доступности.

Золотые окружности отмечают границу, фиолетовые вершины - компоненты леса, не встречающие границу; пунктир показывает невыбранные рёбра исходного пути. Цветные области на схемах разбиений обозначают блоки и не являются рёбрами. Положение вершин на рисунках не задаёт резистивных расстояний.

```bash
python checks/boundary/draw_contraction.py
```

Программа добавляет три SVG к заметке о стягивании: цикл между двумя блоками, три фактор-графа P5 и петля с параллельными рёбрами во взвешенном треугольнике. Используются графические примитивы соседнего `draw_forest_states.py`. На рисунке цикла золотой пунктир обозначает вспомогательные пары отождествления, а не рёбра исходного графа. Проводимости показаны подписями; длины нарисованных связей метрического смысла не имеют.

```bash
python checks/boundary/draw_pairing.py

Программа создаёт три новых SVG: два пути с двухточечной границей, таблицу пяти трёхточечных состояний и сравнение двух параллельных копий с одним общим ребром. Использует примитивы соседнего `draw_forest_states.py`. В третьей заметке также повторно используется опубликованный рисунок «Один партнёр и две разметки пути»; отдельная копия не создаётся.

```

Программа создаёт три новых SVG: граничное исключение P5 с остовным масштабом, сочленение двух P5 и две электрически неразличимые части с разными лесными паспортами. Использует примитивы `draw_forest_states.py`. Рисунок «Три леса одного граничного состояния» используется из первой заметки без дублирования файла. Рисунки показывают смежность, границы и проводимости; длины связей не задают резистивные расстояния.

```bash
python checks/boundary/draw_reduction.py
```

Программа создаёт три SVG: все пятнадцать разбиений, сокращённую матрицу с остовными блоками и пример переноса пересекающегося состояния. Использует `Drawing` из `draw_forest_states.py` и проверенные данные матрицы из `verify_reduction.py`. В галерее цветные области обозначают блоки, а не рёбра; пересечение областей не создаёт вершину. В графовом примере граница и метки вершин согласованы, общих рёбер нет.

```bash
python checks/boundary/draw_spectral_boundary.py
```

Программа создаёт четыре SVG: совпадающие лесные паспорта с разными спектрами, сочленение двух путей, одно общее ребро и две параллельные копии, вход и выход ядра. Использует `Drawing` из `draw_forest_states.py`; данные примеров проверяются в `verify_spectral_boundary.py`. Расположение вершин показывает инцидентность, а не резистивные расстояния. Во всех схемах отмечены граница, соответствие вершин и правило учёта рёбер.
