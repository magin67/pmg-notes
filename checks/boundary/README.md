# Проверки граничных лесных состояний

Скрипты сопровождают первую русскую заметку серии «Граничные полиномы и сочленение графов». Для запуска достаточно стандартной библиотеки Python 3.10 или новее. Запускать из корня репозитория без флага `-O`, отключающего проверочные утверждения `assert`.

## Точные проверки

```bash
python checks/boundary/verify_forest_states.py
```

Проверка перебирает подмножества различимых рёбер. Циклы выявляются объединением компонент; все вершины сохраняются, включая изолированные. Из каждого принятого леса независимо извлекаются разбиение границы, внутренние компоненты и признак рощи.

Проверяются:

- все 16 лесов единичного пути P5 с границей `{a,c,e}`, каждый коэффициент пяти полиномов состояний, сумма `(1+t)^4` и девять рощ;
- тот же путь с весами `2,3,5,7`;
- добавление изолированной внутренней вершины: полиномы не меняются, число внутренних компонент увеличивается на один;
- два сочленения с одним партнёром на границе `{x,y,z}`, содержащим единственное ребро `xy`: по 32 подмножества рёбер для каждого результата;
- различимые параллельные рёбра с рациональными весами, несвязный граф, одноточечная граница и граница из всех вершин.

Для всех этих случаев сумма полиномов состояний сопоставляется с прямой лесной суммой, а коэффициенты рощ - с непосредственным условием, что каждая компонента встречает границу. Проверки примеров не заменяют общих доказательств в заметке.

## Рисунки

```bash
python checks/boundary/draw_forest_states.py
```

Программа создаёт пять SVG рядом с русской заметкой. Она использует только стандартную библиотеку Python и соседний `verify_forest_states.py`; дополнительные пакеты не требуются. Текст в SVG остаётся редактируемым, каждый рисунок содержит заголовок и описание доступности.

Золотые окружности отмечают границу, фиолетовые вершины - компоненты леса, не встречающие границу; пунктир показывает невыбранные рёбра исходного пути. Цветные области на схемах разбиений обозначают блоки и не являются рёбрами. Положение вершин на рисунках не задаёт резистивных расстояний.
