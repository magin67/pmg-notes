# Проверки метрического распределения

Комплект сопровождает заметку «Влияние связей и метрическое распределение». Все математические проверки используют `fractions.Fraction` и стандартную библиотеку Python 3.10+. Базовые функции обращения матрицы и независимого перебора лесов импортируются из `../variations/verify_single_edge.py`.

Запуск из корня репозитория:

```text
python checks/metric-distributions/verify_influence.py
python checks/metric-distributions/draw_influence.py
```

Рисунки требуют Matplotlib; публикуются две SVG-схемы. PNG предназначены для локальной визуальной проверки.

Проверяются цепочка на трёх вершинах, единичный и взвешенный треугольники, взвешенный путь на четырёх вершинах и взвешенный квадрат. Для всех пар двухточечных векторов проверяются квадраты и смешанные формы. Прямое обращение изменённого лапласиана сопоставляется с лесными резистенсами, поляризацией, конечной формулой влияния и восстановлением коэффициента из конечной пробы. Проверяются существующие и отсутствующие связи, добавление и допустимое ослабление; сумма коэффициентов проверяется отдельно.

Результаты сохраняются в `influence-results.json`. Примеры и подписи к рисункам используют проверенные значения. Общие доказательства находятся в самой заметке; конечная вычислительная проверка их не заменяет.

## Пересечение путей на дереве

Заметку «Пересечение путей как поле влияния на дереве» сопровождают:

```text
python checks/metric-distributions/verify_tree_paths.py
python checks/metric-distributions/draw_tree_paths.py
```

Проверяются единичная и взвешенная цепочки на пяти вершинах, взвешенная звезда и разветвлённое дерево на шести вершинах. Для всех упорядоченных пар различных вершин и всех пар соответствующих векторов сравниваются координаты единственных путей, обращение редуцированного лапласиана и независимые лесные резистенсы. Проверены точный носитель, знаки, ортогональность рёбер, совместные изменения и 27900 независимых конечных влияний при удвоении, добавлении 1/3 и уменьшении проводимости вдвое. Отдельно проверено добавление отсутствующей связи к цепочке с непересекающимися путями.

Результаты: `tree-path-results.json`. Три SVG-рисунка создаются скриптом `draw_tree_paths.py`; числовые подписи взвешенного примера берутся из проверенного JSON. Общие утверждения доказаны в заметке.

## Поле влияния на графах с циклами

```text
python checks/metric-distributions/verify_cycles.py
python checks/metric-distributions/draw_cycles.py
```

Восемь графов: единичный треугольник, треугольник с усиленной связью, треугольник с проводимостями 2, 3, 5; единичный и взвешенный квадраты, квадрат с равновесной и неравновесной перемычкой, последовательная детализация треугольника. Проверены 3195 конечных влияний для квадратов и смешанных форм: независимое обращение изменённого лапласиана сопоставляется с перебором остовов и разделяющих лесов. Дополнительно проверяются закон сохранения токов, смена вспомогательных ориентаций, параллельные маршруты, нулевая перемычка, взаимодействие конечных изменений и последовательное разделение ребра для всех смешанных форм на старых вершинах.

Результаты сохраняются в `cycle-results.json`; четыре SVG-рисунка строятся по этим данным. Таблица метрических оценок выходных форм независимо вычисляется из рёберных резистенсов.
