# Проверки матроидных параметров и лесных характеристик

[English version](README.en.md)

Скрипты сопровождают семь заметок серии на русском и английском языках. Используется точная рациональная арифметика `fractions.Fraction`; для проверок достаточно стандартной библиотеки Python 3.10 или новее. Запускать из корня репозитория без флага `-O`, который отключает проверочные утверждения `assert`.

## Состав проверок

| Скрипт | Покрытие | Независимые способы сопоставления |
| --- | --- | --- |
| `verify_cycle_matroid.py` | 6 графов, 84 леса | Аксиомы независимости; леса и внешние координаты по минорам; матричный гриниан и центрированные 2-леса; рёберные вероятности; корневые полиномы. |
| `verify_forest_coefficients.py` | 70 графов, 215 рёберных рекурсий | Перебор лесов, произведения кофакторов индуцированных блоков и рекурсия удаления-стягивания; прямой и когрейдовый порядок; обычный и корневой полиномы гриниана $K_4$. |
| `verify_forest_power_sums.py` | 46 связных графов, степени до 8 | Формальный логарифм и тождества Ньютона; обратное восстановление; матричные следы; масштабирование и одноточечное сочленение. |
| `verify_forest_scales.py` | 50 графов, 146 уровней когрейда | Обычные и корневые леса, допустимые расширения; главные миноры; неравенства, масштабирование и сочленение. |
| `verify_edge_resistances.py` | 53 графа, 200 рёбер, 84 упорядоченных пары и тройки деревьев | Перебор деревьев, производные остовного полинома, матрица Грина и сопротивления; интерпретация $H_q$ через пересечения. |
| `verify_resistance_radius.py` | 54 графа, 215 выборов опорной вершины | Независимая геометрическая конструкция описанной сферы, лесная формула и рёберная поправка; масштабы и сочленение. |
| `verify_gluing_invariance.py` | 49 одноточечных сравнений и 49 переворотов Уитни | Леса и граничные состояния; сохранение и изменение параметров при разных склейках; примеры общего ребра. |

Набор из 70 графов включает все 64 подграфа $K_4$ с проводимостями шести рёбер $1,2,3,5,7,11$, в том числе пустой и несвязные подграфы. Ещё шесть случаев: единичные $K_4$ и $C_4$, треугольник с весами $1,2,3$, путь с весами $1,1/2,3$, трёхвершинный граф с парой параллельных рёбер и трёхвершинный путь с петлёй. Метки параллельных рёбер не объединяются, изолированные вершины сохраняются. При удалении моста проверяется изменение ранга в обращённой рекурсии.

## Запуск

```bash
python checks/matroid/verify_cycle_matroid.py
python checks/matroid/verify_forest_coefficients.py
python checks/matroid/verify_forest_power_sums.py
python checks/matroid/verify_forest_scales.py
python checks/matroid/verify_edge_resistances.py
python checks/matroid/verify_resistance_radius.py
python checks/matroid/verify_gluing_invariance.py
```

Все файлы следует сохранять вместе. Общие функции перечисления лесов, полиномиальной и матричной арифметики находятся в `verify_forest_power_sums.py`; остальные проверки импортируют их прямо или через соседние скрипты. `verify_forest_coefficients.py` также использует функцию компонент из `verify_cycle_matroid.py`. Запуск импортируемого файла отдельно не требуется: его основной сценарий защищён условием `if __name__ == "__main__"`.

## Рисунки

`draw_series_figures.py` строит девять SVG к заметкам 1-5, `draw_radius_figures.py` - три SVG к заметке о радиусе, `draw_gluing_figures.py` - три SVG к заключительной заметке. Это отдельные программы; для выполнения численных проверок запускать их не нужно. `translate_figures_en.py` воспроизводит 15 английских SVG из сохранённых русских оригиналов, переводя подписи, заголовки и описания доступности. Готовые SVG сохранены рядом с заметками и не требуют построения при чтении библиотеки.

Проверки конечных наборов примеров дополняют математические доказательства в заметках и не являются доказательствами общих утверждений.
