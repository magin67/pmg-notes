# Точные проверки серии «Гриниан и дуальность полиформ»

Требуется Python 3.10 или новее; внешние пакеты не нужны. Все вычисления выполняются с fractions.Fraction. Проверки выводят JSON в стандартный вывод, не изменяют заметки и не сохраняют результаты в файлы.

Из корня репозитория:

    python checks/dual/verify_vector.py
    python checks/dual/verify_exponential.py
    python checks/dual/verify_variations.py
    python checks/dual/verify_typical.py
    python checks/dual/verify_potentials.py
    python checks/dual/verify_symmetry.py
    python checks/dual/verify_toponomes.py

Можно запускать любой скрипт по абсолютному пути из другого рабочего каталога. Нужно сохранить соседние файлы этой папки: дополнительные проверки используют операции из verify_vector.py и exterior_checks.py. Не запускать с параметром Python -O: проверки используют assert.

| Скрипт | Что сопоставляется | Объём |
| --- | --- | --- |
| [verify_vector.py](verify_vector.py) | Векторные факторы, знаковые леса, миноры обратного редуцированного лапласиана, исходные лесные суммы и обе стороны дуального удаления | 9 графов на 2-6 вершинах |
| [verify_exponential.py](verify_exponential.py) | Внешние степени и все миноры, факторизация, дополнительные грейды, центрированный образ | 29 матриц порядков 1-5; 15 невырожденных симметричных случаев дуальности; 3 графовых примера |
| [verify_variations.py](verify_variations.py) | Полярная форма, исходные леса, удаление вершин, присоединение вершины, определитель и прямой перебор новых деревьев | 6 графов; 64 удаляемых набора; 27 присоединений |
| [verify_typical.py](verify_typical.py) | Все внешние грейды, миноры, кофакторы на блоках, суммы по разбиениям и корневые суммы | 9 графов на 4-10 вершинах, включая Петерсена; дополнительно полные графы и звёзды при 2-8 вершинах |
| [verify_potentials.py](verify_potentials.py) | Потенциалы из произведения форм, лапласовские определители, формула Коши-Бине и минимум при свободных внутренних вершинах | 9 графов; дополнительно полные графы |
| [verify_symmetry.py](verify_symmetry.py) | Тождества сумм квадратов элементов по подмножествам и тождества тетраэдра в пространстве с нулевой суммой | 154 тензорных равенства при 2-8 элементах |
| [verify_toponomes.py](verify_toponomes.py) | Полные топономы из перечисления лесов, две специализации, независимые главные миноры, спектральное обращение и дополнительные исходные леса | Единичный и взвешенный пути P4, K4, C5, звезда и неоднородно взвешенный граф на пяти вершинах |

Внешнее произведение рассчитывается по знакам перестановок базисных индексов, миноры - исключением Гаусса в рациональной арифметике, лесные суммы - отдельным перечислением или кофакторами на заданных блоках. Общий вспомогательный файл exterior_checks.py содержит координатное удаление и независимую проверку лесных миноров.

Наборы графов частично пересекаются. Нулевой код завершения означает, что все проверки данного скрипта прошли. Проверка типовых графов, особенно Петерсена, существенно дольше остальных. Вычисления подтверждают конечные наборы примеров; общие доказательства приведены в заметках.
