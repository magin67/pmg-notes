# PMG Assistant

Локальный прототип MCP для поиска и чтения разделов опубликованной библиотеки PMG. Используется Node.js 24, как в сборке Quartz.

Из корня репозитория, на одной и той же ревизии исходников для сборки сайта и индекса:

```sh
npm ci
npm ci --prefix assistant
npx quartz plugin install
npx quartz build -d pmg-library
node assistant/build-index.mjs
node assistant/check.mjs
node assistant/server.mjs
```

Сборщик сопоставляет `public/static/contentIndex.json` с исходниками и сверяет заголовки с ID в HTML. Сгенерированные страницы тегов и оглавления без исходника пропускаются. Поисковый индекс хранится в `assistant/pmg-index.json` и включает SHA checkout. Чтобы SHA соответствовал цитируемому тексту, собирайте из чистого checkout публикуемой ревизии. Дополнительные позиционные аргументы сборщика задают каталог HTML, путь вывода и базовый URL сайта с завершающим слешем.

Сервер по умолчанию слушает `http://127.0.0.1:3000/mcp` (Streamable HTTP). Параметры окружения `PMG_HOST` и `PMG_PORT` переопределяют адрес и порт. Путь к индексу можно передать первым аргументом. Сервер загружает снимок при запуске. Чтобы перейти на новую ревизию, соберите индекс и перезапустите процесс.

- `search({query})` возвращает до восьми разделов с ID и URL. Поиск лексический, учитывает заголовки, язык запроса и формулы. Варианты вроде `D_L` и `D_{L}` эквивалентны для поиска.
- `fetch({id})` возвращает исходный Markdown раздела с формулами и метаданными. У подраздела собственный ID и отдельный результат поиска. В языковых версиях поле `translation_key` связывает заметки.

Проверка запускает локальный сервер и вызывает оба инструмента через клиент MCP. Она сверяет найденные русские и английские разделы с исходниками и проверяет якоря в HTML.
